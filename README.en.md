# AlertStudio

[Русский](README.md) · [English](README.en.md)

**Make your next bright moment.** An offline notification graphics editor: text, fog, stars and glowing connections in your own composition.

[Application website](https://alexanderzaun.github.io/OS/en/) · [Releases and checksums](https://github.com/AlexanderZaun/OS/releases)

**Windows 10/11 x64 · Portable · Russian / English · Works offline**

![The real AlertStudio interface](<AlertStudio/Не для установки/presentation/assets/editor-en.png>)

## What you can do

- Build compositions from text, procedural fog, small/large stars and networks.
- Configure object sources, layers, blending, opacity and color.
- Preview main effect, intro, outro and assembly, with durations and smooth group opacity.
- Move panels, open detached windows and use Lock, Solo, search, settings copy and history.
- Save transparent current-frame PNGs and move the application with projects to another drive.

## Get started in three steps

1. Download **AlertStudio-0.2.1-Windows-x64.zip** from the [latest release](https://github.com/AlexanderZaun/OS/releases/latest).
2. Extract the complete archive into a writable folder.
3. Run **AlertStudio.exe** and open the example scene.

No Node.js, pnpm or source compilation is required. The first Save writes to `Data/Projects`.

To relocate, close the application and move **the entire folder including Data**. Transfer externally saved files separately.
