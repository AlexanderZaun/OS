# AlertStudio 0.2.1

[Русский](<README.md>) · [English](<README.en.md>)

Офлайн-редактор графики уведомлений для Windows x64. Текст, процедурный туман, звёзды и сеть собираются в композицию с перемещаемыми панелями, историей и прозрачным PNG. Это рабочая экспериментальная версия, а не завершённая студия анимации.

## Готовая программа

Скачайте AlertStudio-0.2.1-Windows-x64.zip из [GitHub Releases](https://github.com/AlexanderZaun/OS/releases/latest), полностью распакуйте в доступную для записи папку и запустите AlertStudio.exe. Node.js, pnpm и установка зависимостей не нужны. Code → Download ZIP содержит исходники, а не готовую программу.

Для переноса закройте приложение и перенесите всю папку вместе с Data. Первое Save записывает проект в Data/Projects; внешние проекты/экспорт переносите отдельно. Обновление: новая папка программы и перенос своей Data при закрытых версиях. [Подробная инструкция](docs/portable.md).

## Папки

| Раздел | Назначение |
|---|---|
| Для установки, рядом с этой папкой | Чистая переносимая программа, ZIP и SHA-256 |
| Не для установки, эта папка | Исходники, зависимости, тесты, документация и временные данные |

Вторая папка не входит в пользовательский ZIP. Исходники и документы из неё всё равно сохраняются в GitHub для разработки; node_modules, artifacts, .test-data и tmp игнорируются. [Полный состав](СОДЕРЖИМОЕ.md).

## Что реализовано

- Каталог самостоятельных/связанных объектов с пользовательским распределением; отдельные шаблоны мелких/крупных звёзд. Один add создаёт один объект, source выбирается первым в свойствах.
- Композиция fog → stars → network, наследуемая область fog, плотность, маска линий, устойчивая топология и сцена-пример.
- Четыре режима: основной эффект, появление, затухание, сборка; общие часы, длительности и линейный fade всей композиции.
- Zoom/pan/fit, выбор/drag; lock, multi-Solo, метки; 13 blend modes, clip, hue/saturation/opacity.
- Поиск RU/EN, отличия от defaults, reset, copy/paste по областям и история до 100 шагов, общая для окон.
- Многофайловые проекты, undo/redo, отдельные recovery drafts, Windows folder lease и trusted runtime extensions.
- PNG текущего кадра с прозрачностью, стилем и выбранной стадией.

Нет keyframes, расширенного появления/затухания, resize существующей сцены, snapping, библиотеки пользовательских пресетов, WebM/GIF, аудио и стриминговых интеграций. [Текущие приоритеты](docs/development-plan.md), [матрица требований](docs/requirements.md).

## Разработка

Откройте терминал в этой папке «Не для установки». Проверенная среда: Windows, Node 24.19.0, pnpm 11.25.0; сборка требует Node 22.12+.

~~~powershell
pnpm install --frozen-lockfile
pnpm build
pnpm start
~~~

Launch.exe здесь запускает рабочую версию с node_modules/dist; это не переносимый AlertStudio.exe. --safe отключает внешние пакеты. В разработке первое Save выбирает папку; в portable оно автоматически использует Data/Projects. Обычное закрытие с dirty спрашивает сохранить/отказаться/отменить. [Закрытие и Recovery](docs/closing.md).

## Проверки и выпуск

~~~powershell
pnpm check
pnpm test:ui
pnpm package:portable
pnpm test:portable
~~~

Результат упаковки — соседняя «Для установки». Пользовательская Data не включается и не удаляется при пересборке. Последний полный программный прогон: 81 функциональный тест, 22 UI-сценария и portable-перенос C: → E:. Другой физический компьютер и полный HiDPI-аудит не проверены. [Проверки](docs/verification.md).

Публикация выполняется по явному запросу: исходники в Git, готовый ZIP/SHA в Releases, аннотированные version/backup tags. Старые tags сохраняются; личные бэкапы не входят в ZIP. [Правила](docs/backups.md).
