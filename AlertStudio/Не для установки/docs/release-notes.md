## Запуск

1. Скачайте ZIP, полностью распакуйте в папку с правом записи.
2. Запустите AlertStudio.exe. Node.js, pnpm и установка зависимостей не нужны.
3. Откройте сцену-пример или создайте проект. Первое «Сохранить» использует Data/Projects.

Для переноса закройте программу и переместите всю папку вместе с Data. Внешние проекты/экспорт переносите отдельно. Для обновления используйте новую папку и свою Data при закрытых приложениях.

## В выпуске

- Двуязычная страница приложения, скриншоты и удобный переход к скачиванию.
- Отдельные READ-ME.ru.txt/READ-ME.en.txt, обновлённая документация RU/EN и разделение исходников/готовой программы.
- Сохранены действующие эффекты, перемещаемые панели, четыре базовые области уведомления, оформление слоёв, PNG, lock/Solo/метки, поиск/reset/copy и история.

Архив не содержит личных проектов, настроек, бэкапов, node_modules или тестовых файлов. SHA-256 доступен отдельным Asset. «Source code» — исходники для разработчиков; для запуска выбирайте ZIP с названием AlertStudio.

PNG и базовые стадии работают; WebM, звук, keyframes и расширенные анимации остаются в плане. Отдельной подписи издателя AlertStudio нет, Windows может предупредить. Другой физический компьютер не проверялся. История прежних выпусков сохранена.
