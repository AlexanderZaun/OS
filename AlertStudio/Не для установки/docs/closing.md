# Закрытие и несохранённые изменения

[Русский](<closing.md>) · [English](<en/closing.md>) · [Оглавление](<README.md>)

Главное окно завершает приложение и все панели; закрытие дополнительного окна закрывает только его. Если проект dirty, общий Dialog предлагает:

| Действие | Результат |
|---|---|
| Сохранить и закрыть | Дождаться Save и деактивации текущего черновика, затем выйти |
| Закрыть без сохранения | Сохранённый проект не менять; дождаться начатого draft write, деактивировать текущий черновик и выйти |
| Отмена / Escape | Сохранить окна, правки и черновик; Enter по умолчанию также отменяет |

В portable первое Save автоматически выбирает Data/Projects; в разработке новый проект требует выбора папки. Отмена picker или ошибка записи оставляет приложение открытым и позволяет retry. Во время завершения операции кнопки/Escape блокируются. Чистый проект не требует подтверждения.

Запрос во время open/save/picker ожидает текущую операцию. Только одно окно владеет подтверждением; main проверяет owner, request ID и фазу. Остальные окна блокируют правки. Ошибка discard сохраняет lease и изменения; другие recovery candidates не деактивируются. Физические файлы старых ревизий не удаляются.

Авария/app.exit не проходят этот Dialog; последние ещё не записанные изменения могут отсутствовать в Recovery. Отдельного native fallback при сломанном renderer и действия «закрыть с черновиком» пока нет. Проверки: close.test.ts, close-smoke.mjs и recovery-smoke.mjs.
