# Состояние направлений

[Русский](<roadmap.md>) · [English](<en/roadmap.md>) · [Оглавление](<README.md>)

Актуальный порядок — [development-plan](development-plan.md). Исторические блоки A–I описывали направления, а не нынешние приоритеты:

| Направление | Сейчас |
|---|---|
| A: исследование | Неизменный reference сохранён, визуальные ориентиры отделены от реализации |
| B: SDK/loader | Внешние panel/effect устанавливаются, перезапуск/проверки работают; SDK 0.1 experimental |
| C: редактор | Панели, меню, камера, drag, layers, styles, инструменты свойств и история работают; геометрия/snapping впереди |
| D: данные | Multi-file, exact versions, validation, backup index, leases и Recovery работают; retention/migrations впереди |
| E/H: эффекты | Fog/stars/network и связи реализованы; прочие системы/advanced behaviors планируются |
| F: blocks/presets | Пример и creation templates есть; user library/modifiers ещё нет |
| G: стадии/монтаж | Четыре базовые области и общие часы есть; keys/advanced stages/montage/audio ещё нет |
| I: экспорт/выпуск | PNG и portable Windows ZIP есть; video/installer/clean-PC testing впереди |

Нельзя использовать старую фразу «экспорт/стадии отсутствуют» для нынешней программы или считать базовый fade завершённой анимацией. [Матрица требований](requirements.md) отделяет работающие части от полной приёмки.
