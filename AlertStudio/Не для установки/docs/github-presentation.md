# Презентация проекта в GitHub

[Русский](github-presentation.md) · [English](en/github-presentation.md) · [Оглавление](README.md)

Пользовательская страница — https://alexanderzaun.github.io/OS/; английская — https://alexanderzaun.github.io/OS/en/. На ней показаны программа, реальные скриншоты, возможности, запуск и скачивание ZIP. Она не показывает дерево исходников. Вкладка Code публичного репозитория остаётся файловым браузером GitHub; скрывать её средствами README нельзя.

Корневые README.md/README.en.md представляют приложение и ведут к готовому выпуску. Подробные инструкции разработчика остаются в «Не для установки». About получает описание и URL витрины; исходники и архивы имеют разные ссылки.

Исходники страницы находятся в presentation, генератор двух языков — tools/build-presentation.mjs. Скриншоты снимаются tools/capture-presentation.mjs из отдельного профиля со сценой-примером; личные проекты и данные не используются. tools/test-presentation.mjs проверяет RU/EN, ссылки и 1440/900/390 px. Скриншоты показывают действующие функции.

GitHub Pages использует отдельную ветку codex/alertstudio-pages с одним статическим сайтом и .nojekyll. tools/github-presentation.mjs проверяет доступ, публикует сайт и обновляет About после проверки доступности. Не меняйте чужую Pages-конфигурацию и приватность репозитория. Обновление сайта сопровождает явную публикацию; новых платных сервисов и фоновых задач нет.

При следующем выпуске обновите package.json, обе инструкции/README/release notes, выполните build-presentation и проверки, затем portable-процедуру с backup tag. Публикуйте готовый ZIP в Releases и только затем активируйте витрину с новой ссылкой. Старые assets не перезаписываются.
