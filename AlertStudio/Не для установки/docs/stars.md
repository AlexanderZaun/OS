# Звёздное поле

[Русский](<stars.md>) · [English](<en/stars.md>) · [Оглавление](<README.md>)

Встроенный stars 0.1.0 имеет 48 definitions и два шаблона добавления: мелкие/крупные. Доступны самостоятельное поле и поле по одному fog source, область/поворот, seeded count 0–5000, цвет/палитра, ядро/halo, формы, мерцание, движение, привязка к клубам, блики и короткие аналитические следы.

Count сохраняет начальный префикс звёзд. Дрейф самостоятельного поля оборачивается по области с затуханием у края; глубина изменяет скорость. Cloud mode наследует геометрию и использует контур или плотность; attachment выбирается по базовым положениям клубов. Seek не зависит от порядка кадров. Нулевые count/opacity дают пустой выход.

Renderer использует ограниченный кеш спрайтов, не отдельную полноразмерную поверхность на звезду; dispose освобождает кеш. Network получает те же текущие/rest координаты и отдельную densityAlpha, поэтому обычное мерцание не перестраивает граф.

Ring/bokeh, отдельный угол символа, вращение по движению, оттенок/насыщенность каждой звезды, flying/flow, несколько источников и длинные history trails пока не реализованы. У слоя уже есть общий hue/saturation, но это не случайный разброс звёзд. См. [связи](linked-scene.md), [плотность](fog-density.md).
