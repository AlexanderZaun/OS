# Система оформления

[Русский](<design-system.md>) · [English](<en/design-system.md>) · [Оглавление](<README.md>)

ui-kit/theme.css — единственный источник палитры и общих контролов. Используйте --studio-bg, --studio-surface, --studio-raised, --studio-sunken, --studio-border, --studio-text, --studio-muted, --studio-accent, --studio-danger и --studio-success. Не добавляйте отдельную палитру, глобальный reset или селекторы чужих панелей.

Наследуйте шрифт host. Основные контролы используют общие отступы, focus/hover/disabled и radius 6 px. Текст ошибки и dirty-индикаторы должны быть понятны без цвета. Длинные подписи имеют полные aria-label/title; сокращение не должно менять accessible name.

Все in-app диалоги используют ui-kit/Dialog.tsx: portal в body, focus trap, Escape, возврат фокуса, прокрутка и closeDisabled во время записи. Диалог закрытия приложения тоже использует общую тему; native file pickers остаются системными. F10 не должен выходить из модального окна.

SettingHeading связывает label, единицу, звёздочку отличия и reset. Связи располагаются первыми; поиск может показывать скрытые поля с объяснением условия. Сброс и вставка отключены для заблокированного получателя. Поля применяются по Enter/blur и отменяются Escape там, где задан отложенный ввод.

Dockview-переменные задаются в workspace adapter; меню использует portal и viewport-ограничения. Каталог — обычная панель, история сначала открывается вкладкой рядом со свойствами. Текущие размеры описаны в [компактной компоновке](compact-layout.md), а не в старых checkpoint-значениях.

При изменении UI осматривайте 900×650 и 1920×1080, узкие панели, Dialog и длинные RU/EN подписи. Проверка ОС DPI, screen readers и полный accessibility-аудит ещё не выполнены.
