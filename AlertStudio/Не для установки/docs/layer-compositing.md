# Оформление слоёв и PNG

[Русский](<layer-compositing.md>) · [English](<en/layer-compositing.md>) · [Оглавление](<README.md>)

Оформление отделено от effect settings: normal/screen/multiply и остальные режимы из contracts/layer.ts (13), clip, hue −180…180°, saturation 0…200%, opacity 0…100%. По умолчанию normal, clip off, hue 0, saturation/opacity 100. Числа целые; неверный ввод не изменяет модель.

Clip использует альфу ближайшего предыдущего видимого слоя в порядке рисования, а не обязательно источник эффекта. Solo меняет список рисуемых слоёв. Источники продолжают отдавать исходные primitives; смешивание не меняет их геометрию или данные. Пустой видимый слой остаётся отдельным слоем и важен для clipping.

CanvasBackend применяет стиль через временные поверхности, затем групповую прозрачность стадии один раз ко всей композиции. Старые render-вызовы без RenderLayer поддерживаются. Изменение стиля — обычная отменяемая правка; сохранённые значения имеют отдельные файлы.

«Файл → Экспорт кадра в PNG…» фиксирует проект/время/область и рендерит отдельный кадр в разрешении сцены. Сохраняются прозрачность, стиль, clip и стадийный fade; checkerboard, selection и UI исключены. Диалог может быть отменён без записи; ошибки отображаются без сообщения об успехе. Main проверяет PNG и размер до записи. Это текущий кадр, не последовательность или WebM.

Проверки сравнивают пиксели и альфу, размер файла, отмену/ошибку, fade и неизменность проекта/истории. См. [формат](project-format.md) и [стадии](notification-workspaces.md).
