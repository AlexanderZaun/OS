# Поиск и сброс параметров

[Русский](<settings-tools.md>) · [English](<en/settings-tools.md>) · [Оглавление](<README.md>)

⌕ в свойствах открывает поиск, фильтр «Изм.» и reset/copy/paste. Повторное нажатие очищает поиск/фильтр. Sources остаются первым разделом; инструменты локальны для представления и сбрасываются при выборе другого объекта.

Поиск учитывает RU/EN названия, ID, группы и options независимо от языка UI; регистр и е/ё нормализуются. Все слова должны встречаться в metadata. Единицы, пользовательский текст уведомления и имена источников не индексируются. Escape очищает запрос. Поиск/фильтр находят скрытые поля: они отключены с «Доступно при…», а управляющие условия показаны рядом, включая AND.

Звёздочка и счётчик означают отличие от defaults установленной версии эффекта, а не от сохранённого проекта. Поэтому шаблон примера может сразу иметь отличия. Отсутствующее значение, использующее default, изменением не считается.

↶ сбрасывает один параметр. Общий Dialog отдельно сбрасывает все известные значения эффекта (включая скрытые, координаты и sources) либо оформление слоя. Фильтр не ограничивает полный reset. Неизвестные ключи, имя/visibility/lock/Solo/tag сохраняются. Каждый reset — один undo; no-op не создаёт шаг.

Lock запрещает reset, но не поиск. Неточный модуль нельзя сбросить по чужим defaults. Core проверяет ключи, scope и revision атомарно. Диалог закрывается при смене ревизии/выбора/операции; отмена ничего не меняет. См. [copy/history](copy-history.md).
