# Четыре области уведомления

[Русский](<notification-workspaces.md>) · [English](<en/notification-workspaces.md>) · [Оглавление](<README.md>)

«Основной эффект», «Появление», «Затухание» и «Сборка» — режимы одной композиции. Объекты и связи общие. Индивидуальные значения по стадиям, keyframes, задержки объектов и монтаж пока не реализованы.

По умолчанию intro/main/outro = 1/5/1 с. Появление/затухание: 0.1–60 с; основной показ: 0.1–3600 с; шаг 0.1. Enter/blur применяет, Escape отменяет, invalid ввод не записывается. Плавность — линейная прозрачность всей композиции; выключенный fade сохраняет видимость стадии до её границы.

В сборке [0,1) — intro, [1,6) — main, [6,7) — outro; начиная с 7 — прозрачный конечный кадр. effectTime непрерывен. Изолированное intro начинает с 0, outro — с intro+main; основной эффект — отдельный preview от 0 со своим периодом.

Смена области останавливает playback, обнуляет время и отключает repeat; повтор можно включить снова. Уже выбранная область не сбрасывает время. Конечная стадия останавливает часы, повторный Play начинает с нуля. Open/New/Recovery/пример возвращают main. Навигация и seek не меняют Project; длительности/fade — правки с undo и autosave.

Group opacity применяется один раз к объединённому изображению. UI/checkerboard не затухают и не экспортируются. PNG уже поддерживает выбранную стадию и прозрачность; WebM отсутствует.

Project.notification опционален (version 1), defaults заданы отдельно. Явное редактирование добавляет marker notification:1 и отдельные notification/settings/&lt;key&gt;.json в ревизии. Legacy не переписывается; повреждение требует валидного fallback. Область/часы общие для окон, но не сохраняются в Project.
