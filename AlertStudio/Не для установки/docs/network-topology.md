# Топология сети

[Русский](<network-topology.md>) · [English](<en/network-topology.md>) · [Оглавление](<README.md>)

«Ближайшие сейчас» выбирает соседей по текущим позициям каждый кадр. «Устойчивые связи» выбирает пары по rest coordinates baseX/baseY, затем рисует текущие x/y тех же ID. Оба режима доступны для segments/triangles/chains и сохраняются с undo.

Дистанция отбора относится к rest positions; текущая длина управляет видимостью, последние 20% диапазона плавно гасят ребро. За пределом пара остаётся в графе и может появиться снова. Совпадающие концы не рисуются. При clip участие определяется базовым положением, выход текущего конца скрывает линии.

Для внешних источников без rest coordinates используется fallback x/y: стабильность не гарантируется. Изменения seed/count/distribution/geometry/attachment/distance/neighbors могут перестроить граф; устойчивость относится к времени анимации. Wrap самостоятельного поля остаётся прежним.

До 1000 точек/3000 рёбер; fog mask имеет отдельный бюджет. Расчёт без history state даёт одинаковый результат при прямом seek и reopen. Старые проекты и пример по умолчанию используют текущих ближайших соседей.
