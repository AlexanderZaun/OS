# Prioritized development plan

[Русский](<../development-plan.md>) · [English](<development-plan.md>) · [Contents](<README.md>)

This is the current user-agreed order. The 218-idea catalog is not an implementation queue. Build AlertStudio's own solutions rather than copying the HTML. Advanced stages remain planned; their basic foundation was introduced early so future effects can be tested in all four workspaces.

1. Notification model and compatibility: foundation implemented, extended with later stages.
2. Main effect/intro/outro/assembly: basic durations, fades, shared preview and storage implemented.
3. Shared rendering: 13 blend modes, clipping, hue/saturation/opacity and PNG implemented.
4. Editor: lock, multi-Solo, tags, search/changed/reset, scoped copy/paste and visible history implemented.
5. Next area: geometry/scene — corner handles, proportions, grid snapping, guides, resize policies/anchor, subsystem scales/density, transparent margins, backgrounds/readability, frame stepping and performance indicators.
6. Fog: multiple sources/weights, shapes, movement/structure presets, two-color gradients, erosion/voids.
7. Text: name/amount/message, blocks, typography, wrap/fit, outline/shadow/backplate and test notifications.
8. Dark Base: its own region, fog/text links and relative geometry.
9. Stars: ring/bokeh, outline/no fill, angle, hue/saturation scatter, flying/emission, velocity alignment, fog flow and multi-source/weights.
10. Shared wind/vortex and collisions/reactions with reproducible seeking.
11. Network: new construction, endings, curves/moving points; then Edge Light, contour/strands/tails/sparks.
12. Advanced intro/outro/assembly: inheritance, per-object parameters, delays/keys/time organization agreed before implementation.
13. User object/composition/notification presets, settings export, link remapping and transitions.
14. WebM: ranges/stages, FPS, dimensions/quality/alpha, progress/cancel and deterministic frame calculation.

Each stage ends with a verifiable function, save/open/undo/RU/EN and checks in four workspaces. Audio, integrations, AI and a live OBS server are outside near-term scope and must not start automatically from older catalogs. Publication requires a request and the [portable/backup procedure](portable.md).
