# Direction status

[Русский](<../roadmap.md>) · [English](<roadmap.md>) · [Contents](<README.md>)

The [development plan](development-plan.md) defines current order. Historical A–I blocks described directions, not today's priorities:

| Direction | Current status |
|---|---|
| A: research | Immutable reference retained; visual targets separated from implementation |
| B: SDK/loader | External panel/effect install, restart and checks work; SDK 0.1 experimental |
| C: editor | Panels, menus, camera, drag, layers, appearance, property tools and history work; geometry/snapping remain |
| D: data | Multi-file storage, exact versions, validation, backup index, leases and Recovery work; retention/migrations remain |
| E/H: effects | Fog/stars/network and sources implemented; other systems/advanced behavior planned |
| F: blocks/presets | Example and creation templates exist; user library/modifiers do not |
| G: stages/montage | Four basic workspaces and shared clocks exist; keys/advanced stages/montage/audio do not |
| I: export/release | PNG and portable Windows ZIP exist; video/installer/clean-PC testing remain |

Do not apply old export/stages absent claims to the current program or equate basic fade with complete animation. The [requirements matrix](requirements.md) separates working subsets from full acceptance.
