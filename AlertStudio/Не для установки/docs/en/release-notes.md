## Get started

1. Download the ZIP and extract everything into a writable folder.
2. Run AlertStudio.exe. No Node.js, pnpm or dependency installation is required.
3. Open the example scene or create a project. First Save uses Data/Projects.

Close the app and move the entire folder including Data to relocate. Transfer external projects/exports separately. Update using a fresh application folder and your Data while both apps are closed.

## In this release

- Bilingual application website, screenshots and prominent downloads.
- Separate READ-ME.ru.txt/READ-ME.en.txt user guides, updated RU/EN documentation and distinct source/runnable folders.
- Existing effects, movable panels, four basic notification workspaces, layer appearance, PNG, lock/Solo/tags, search/reset/copy and history remain available.

The ZIP excludes personal projects/settings/backups, node_modules and test files. SHA-256 is a separate Asset. Source code archives are for developers; choose the ZIP named AlertStudio to run the app.

PNG and basic stages work; WebM, audio, keyframes and advanced animation remain planned. No separate AlertStudio publisher signature is provided, so Windows may warn. Another physical computer was not tested. Previous releases remain intact.
