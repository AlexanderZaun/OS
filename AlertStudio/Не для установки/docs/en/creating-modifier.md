# Modifiers: planned contract

[Русский](<../creating-modifier.md>) · [English](<creating-modifier.md>) · [Contents](<README.md>)

Runtime modifier registration is not implemented. The manifest currently supports panel/effect kinds; do not offer installation of a nonexistent modifier package.

The plan separates simulation changes from image processing and defines stack order, base versus evaluated values, seed/seeking, lifecycle and backend capabilities. Saved settings must remain independent of rendering technology. Glitches and refraction require separate render-path investigation.

Implementation needs an agreed contract, compatibility/storage checks, an external example and cancellable preview/export. See the historical [animation and modifiers catalog](plan/07-animation-and-modifiers.md); current priority comes from the [development plan](development-plan.md).
