# Block 8. Presets and templates

[Русский](<../../plan/08-presets-and-templates.md>) · [English](<08-presets-and-templates.md>) · [Contents](<../README.md>)

Status in 0.2.0: Example and creation templates exist; user library does not.

This is a requirements/proposal catalog, not a claim of full implementation or the current queue. Follow the [development plan](../development-plan.md). Original numbering is retained; topic pages explain partial progress. Every new area requires deterministic seeks, independent copies, save/open/undo/RU/EN, bounded resources and four-stage checks.

109. Effect presets. Name/description/thumbnail/definition version, applied in one undoable action.

110. Style presets. Shared palette/fonts/radii/glow rules across scene objects.

111. Scene templates. Structure/effects/assets and replaceable fields with dependencies shown beforehand.

112. Categories/favorites. Name/tag search, recent items, user folders and sorting.

113. Preset export. Portable package with preview/version and included-resource licenses.

114. Preset migration. Report changed/unknown parameters and preserve originals until confirmation.
