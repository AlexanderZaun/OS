# Block 2. Lightning and glitches

[Русский](<../../plan/02-lightning-and-glitches.md>) · [English](<02-lightning-and-glitches.md>) · [Contents](<../README.md>)

Status in 0.2.0: Proposals; not the next mandatory stage.

This is a requirements/proposal catalog, not a claim of full implementation or the current queue. Follow the [development plan](../development-plan.md). Original numbering is retained; topic pages explain partial progress. Every new area requires deterministic seeks, independent copies, save/open/undo/RU/EN, bounded resources and four-stage checks.

179. Branching lightning. Endpoints/scene edge, core width, branches/jaggedness/halo, flash duration/frequency/seed for impact titles.

180. Electrical arcs. Moving object-linked discharges with anchors/length/jitter/count/rebuild speed and predictable deletion handling.

181. Contour discharge. Electricity along text/frame/logo with active length/direction/speed/branches/sparks; requires contour/mask.

182. Ball lightning. Stylized 2D luminous core/internal arcs with radius/pulse/count/halo intensity.

183. Storm flashes. Cloud/region illumination with strength/duration/short pulse series/pauses, independent of sound.

184. Electric sparks. Contact bursts with cone/count/speed/trail length/fade, preferably a shared-particle preset.

185. Plasma strand. Glowing flexible waves with width/amplitude/frequency/gradient/interwoven filaments for links/dividers.

186. Energy shield. Circular/polygonal arc shells with size/grid/pulse/local impulses/transparency; distortion later.

187. Strip displacement. Brief horizontal/vertical fragments with width/count/max offset/frequency/duration.

188. RGB separation. Channel displacement and return with distance/angle/strength/envelope while preserving readable modes.

189. Digital blocks. Drop/duplicate/recolor rectangles with size/density/palette/hold time; visual only, never file corruption.

190. VHS artifacts. Noise bands, line jitter, blurred color edges and instability, individually switchable.

191. CRT. Scanlines/dot mask/glow/vignette/curvature scaled to output resolution; curvature needs another image pass.

192. Signal loss. Freeze/fragment/recover with duration/frequency/order and bounded cached-frame seeking semantics.

193. Text glitch. Temporary character substitutions/desynchronization/decryption with alphabet/fraction/recovery speed; original text unchanged.

194. Hologram scan. Scanning bands, translucent slices and flicker with color/spacing/direction/assembly time/residual glow.
