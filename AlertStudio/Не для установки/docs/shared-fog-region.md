# Общая область тумана

[Русский](<shared-fog-region.md>) · [English](<en/shared-fog-region.md>) · [Оглавление](<README.md>)

Fog может быть самостоятельным или наследовать область другого fog. Наследуются эффективные центр, размеры, поворот, форма и неровность контура. Цвет, плотность, brightness/opacity, softness, просвет, текстура, качество, клубы и движение остаются собственными.

Связанный режим задаёт source, мировые offsetX/Y, масштаб 1–400% и добавочный поворот −360…360°. Drag меняет оба offset одним patch/undo, включая точку mouse release. В цепочке масштабы перемножаются, повороты и мировые смещения складываются; offsets не вращаются/масштабируются источником.

Возврат в самостоятельный режим использует прежние собственные значения; ссылка/relative settings сохраняются. Перенос эффективной геометрии в собственные значения пока отсутствует. В сцене-примере fog 2/3/4 наследуют fog 1.

Скрытый source вычисляется, удалённый диагностируется, undo возвращает связь. Пустой output source отключает потребителей; используйте visibility для невидимого источника. Циклы, включая сохранённые неактивные ссылки, проверяются до изменения. Отдельного невизуального region-объекта и нескольких источников одного поля ещё нет. Геометрический density sampler уже реализован: [плотность](fog-density.md).
