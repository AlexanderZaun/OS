# Выбор и перемещение

[Русский](<canvas-editing.md>) · [English](<en/canvas-editing.md>) · [Оглавление](<README.md>)

Левый щелчок выбирает верхний подходящий объект; пустой щелчок снимает выделение. Поддерживаются editor bounds text/fog/stars, включая поворот области. У полей hit-test включает прозрачную геометрическую область. Рамка — DOM overlay и не попадает в PNG.

Перетаскивание меняет локальный preview; при отпускании отправляется один атомарный patch с координатами и исходной revision. Core проверяет диапазоны/step и создаёт один undo. Свойства во время жеста показывают подтверждённое состояние.

Escape, потеря захвата/фокуса, resize/изменение камеры, операция проекта и новая authoritative revision отменяют жест. Правка из другого окна не затирается старым drag. Во время object drag не начинается zoom/pan. Рука/Space/средняя кнопка вне жеста перемещают камеру. Заблокированный слой не перемещается.

Эффект без Effect.editor редактируется через слои/свойства, но не hit-test на Canvas. Touch пока перемещает камеру. Ручки размера/поворота, snapping, multiple selection и выбор сквозь перекрывающиеся поля не реализованы. См. [SDK](module-sdk.md) и [блокировку](layer-editor.md).
