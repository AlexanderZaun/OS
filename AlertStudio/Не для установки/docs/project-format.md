## Структура

project.json содержит id, name, format, revision и scene. Ревизия — revisions/&lt;uuid&gt;/. modules.lock.json фиксирует точные версии эффектов и SDK. scenes/main/scene.json перечисляет объекты; settings/{width,height,background}.json хранят отдельные значения сцены. Каждый objects/&lt;id&gt;/object.json хранит metadata и settingIds; settings/&lt;key&gt;.json — одно значение в объекте {value}.

Опциональные значения уведомления записываются отдельно. Маркер layer:1 включает objects/&lt;id&gt;/layer/settings/{blend,clip,hue,saturation,opacity}.json. Маркер editor:1 включает editor/settings/{locked,solo,tag}.json. Отсутствующие маркеры старых проектов не добавляются до явного редактирования. Повреждённое или неполное объявленное дерево не принимается. Неизвестные эффекты и значения сохраняются; код проекта не исполняется.

## Запись и восстановление

Ревизии неизменяемы. Save записывает новое дерево, синхронизирует JSON и только затем переключает индекс через rename. project.previous.json указывает на проверенную предыдущую ревизию; при первом сохранении — на первое полное дерево. Повреждение основного индекса вызывает проверку резервного дерева, предупреждение usedBackup и dirty-состояние. Сохранение в папку другого project ID отклоняется.

Windows FolderLease удерживает named pipe для канонического пути на весь сеанс редактирования; ОС освобождает его при аварии. Автоматическое удаление stale lock-файлов не используется. Координация разных компьютеров на сетевой папке не подтверждена.

Черновики хранятся отдельно: Data/Recovery в portable или userData/Recovery в разработке. Debounce — 700 мс; записи сериализуются и не изменяют сохранённую версию проекта. Восстановление открывает несохранённую копию. Явное Save и намеренный отказ от текущих изменений деактивируют соответствующий черновик. Внутренние portable origins сохраняются относительно папки EXE и перебазируются после переноса.

## Ограничения

Проверены сбои процесса и повреждения файлов, но не физическое отключение питания. Старые ревизии автоматически не чистятся. Assets, keyframe tracks, миграции версий и переносимый архив одного проекта ещё не реализованы. Подробнее: [закрытие](closing.md), [перенос программы](portable.md).
