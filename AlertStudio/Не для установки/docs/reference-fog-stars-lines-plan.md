# Развитие связанной композиции

[Русский](<reference-fog-stars-lines-plan.md>) · [English](<en/reference-fog-stars-lines-plan.md>) · [Оглавление](<README.md>)

Рабочий участок объединяет fog, small/large stars и network в собственной архитектуре. Первый вариант уже реализован: источники, общий clock, пример, наследуемая область, density/mask/topology. Эта страница отделяет следующие расширения от уже работающего.

Целевой ориентир: 1920×1080, cloud 900×480, четыре fog, 1900/70 stars и сеть по крупным. Параметры референса — старт художественного сравнения, не обязательные формулы. Flying/flow и Edge Light исследуются отдельно и не маскируются под network.

Дальнейшие задачи по [общему приоритету](development-plan.md): multi-source UUID links и веса; дополнительные формы/структуры/движения/двухцветность/эрозия fog; flying/flow и вариации stars; общий wind/vortex/collisions; кривые, окончания и движение вдоль network; отдельные Dark Base/Edge Light. Невизуальный region и точный noise-density sampler требуют отдельного решения, а не подмены текущего fog output.

Сохранять независимые экземпляры и значения, скрытые источники, диагностику удаления/неверного типа/цикла, z-order отдельно от graph, deterministic seek, общий clock и undo. Групповое клонирование с remap ссылок, presets и миграции ещё нужны.

Критерий этапа: нет молчаливых разрывов source; прямой seek воспроизводим; save/open сохраняет геометрию; все четыре стадии показывают эффект корректно; renderer освобождает ресурсы; RU/EN, 900×650/1920×1080 и bounded budgets проверены. Сравнение с focused reference не требует pixel parity. [Текущее поведение](linked-scene.md).
