# Навигация по холсту

[Русский](<canvas-navigation.md>) · [English](<en/canvas-navigation.md>) · [Оглавление](<README.md>)

| Управление | Результат |
|---|---|
| Колесо | Zoom к курсору, только над Canvas |
| −/+ и presets | Масштаб относительно центра; диапазон 1–800% |
| Поле процентов | Точное число, точка/запятая и суффикс %; Enter/blur применяет, Escape отменяет |
| Вписать / Home | Вся сцена с автоматическим обновлением при resize панели |
| F | Вписать выбранное с учётом поворота и поля 24 CSS px |
| 1 | 100%: пиксель сцены на CSS-пиксель |
| Центр | Центрировать сцену без изменения масштаба |
| Средняя кнопка / Space+drag | Перемещение вида |
| H / Рука | Постоянный pan левой кнопкой |
| Стрелки / Shift+стрелки | Pan на 40/160 CSS px |
| Shift+колесо | Горизонтальный pan |

Горячие клавиши работают при фокусе Canvas и не перехватывают ввод в полях. Escape отменяет pan. Один touch-контакт перемещает вид, два выполняют pinch/pan; проверены CDP pointer-события, а не физический экран.

У каждого Canvas собственные камера и инструмент. Навигация не меняет Project, dirty, undo, bitmap или playback. Камера сбрасывается при смене проекта и не сохраняется между запусками. Fit selected требует видимого объекта с editor bounds; свечение за геометрическими границами не измеряется. На ограничении 1% огромный объект может не поместиться.
