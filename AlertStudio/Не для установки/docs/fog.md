# Процедурный туман

[Русский](<fog.md>) · [English](<en/fog.md>) · [Оглавление](<README.md>)

Встроенный fog 0.1.0 имеет 36 отдельных definitions. Модель в modules/effects/fog/src/model.ts возвращает нейтральные клубы с seeded-параметрами. Аналитические ветер/завихрения воспроизводятся при произвольном seek без накопления истории. При скорости 100% движение повторяется за заданный период; изменение скорости меняет фактический период обратно пропорционально.

Доступны самостоятельная или наследуемая область, cloud/другие формы, контур/площадь/смешанное распределение, число клубов, плотность, brightness/opacity, текстура, контраст, вытягивание/наклон и эллиптический просвет. Нулевая плотность/opacity даёт пустой выход. Локальные настройки независимы для каждого UUID.

Canvas renderer кеширует текстуры и маски. Качество draft/normal/high использует поверхности 256/384/768 и текстуры 64/96/192 соответственно; они ограничены независимо от размера сцены. Backend освобождает ресурсы при исчезновении объекта/закрытии панели.

Это собственный эффект, не копия алгоритма HTML. Однонаправленная адвекция, GPU, несколько взвешенных источников одного потребителя и библиотека движений ещё впереди. Увеличение сверх размера поверхности смягчает детали. См. [общую область](shared-fog-region.md), [плотность](fog-density.md), [оформление](appearance-controls.md).
