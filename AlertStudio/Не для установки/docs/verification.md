## Переносимая программа

Фактический ZIP распакован в свою тестовую папку. Настоящий EXE запущен из постороннего cwd с PATH только Windows/System32 и заблокированным DNS; HTTP-запросов приложения не зафиксировано. Проверены packaged paths, отсутствие renderer require, автоматический Save без picker, multi-file index, ненулевой Canvas, PNG и отдельные свойства.

После установки orbit и записи черновика папка скопирована C: → E: в путь с кириллицей/пробелами; старый путь сделан недоступным. Сохранились localStorage/раскладка, project open, относительный Recovery origin, восстановление и extension activation. Удаляется только собственный временный каталог E:. Чистая сборка остаётся без Data. Инвентарь проверяет файлы/хеши и отсутствие development-only содержимого; AST-анализ require не путает AJV string templates с исполняемым импортом.

## Артефакты и ограничения

Обновление документации проверено отдельно: pnpm check:docs подтвердил 59 пар RU/EN, локальные ссылки и 218 пунктов в каждом языке; pnpm check повторно прошёл с 81/81 тестами и сборкой. Новый локальный ZIP в «Для установки/Чистая сборка» содержит 82 файла, включая READ-ME.ru.txt и READ-ME.en.txt, и прошёл полный test:portable с переносом C: → E:. Рабочая папка программы с Data не заменялась. Общий UI runner на этом шаге не повторялся: интерфейс не менялся, его последняя проверка остаётся 22/22.

Отчёты — artifacts/*-results.json и artifacts/portable-results.json; UI-снимки — artifacts/screenshots. Последние portable-900/1920 и compact/history/layer/stage снимки осмотрены. Артефакты локальны и не распространяются. Старые подробные записи документации сохранены локально в tmp/docs-before-bilingual-2026-10-18; это не новые результаты тестов.

Не проверены другой физический компьютер/чистая VM, ARM/macOS/Linux, полный HiDPI/screen-reader аудит, физический touchscreen, сетевые папки разных машин, power-loss, длительная нагрузка, peak memory и полный UI FPS. Playwright-контроллер использует среду разработки; тестируемый EXE — свои библиотеки ZIP. Предупреждение Vite о большом UI chunk остаётся и не является ошибкой сборки.
