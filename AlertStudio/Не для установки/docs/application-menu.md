# Меню приложения

[Русский](<application-menu.md>) · [English](<en/application-menu.md>) · [Оглавление](<README.md>)

| Меню | Действующие команды |
|---|---|
| Файл | Новый проект, сцена-пример, открыть, сохранить, сохранить как, PNG, восстановление |
| Правка | Undo/redo, история действий, расширения, язык |
| Сцена | Сведения о сцене и вписывание; resize существующей сцены пока отсутствует |
| Объект | Каталог, имя/дубликат/видимость/порядок/удаление, lock/Solo/метки, copy/paste |
| Воспроизведение | Play/pause, начало, повтор, скорость |
| Вид | Fit scene/selected, 100%, zoom, центр, рука |
| Окно | Показать/восстановить панель, добавить представление, открыть отдельное окно, сбросить раскладку |
| Справка | Сочетания клавиш и сведения о версии |

Управление панелями находится в «Окно»; необязательная панель «Панели» даёт быстрые +/↗. «Показать» использует существующее представление. Отдельное окно — дополнительное представление общей модели, а не перенос экземпляра с локальным состоянием.

F10 фокусирует меню; стрелки/Home/End перемещают фокус, Enter выполняет действие, Escape закрывает список. Списки ограничены viewport и прокручиваются. Dialog удерживает фокус и блокирует меню. Ctrl+N/O/S/Shift+S и Ctrl+Z/Shift+Z используют общие операции; текстовый undo в поле остаётся локальным.

Команды «Вид» работают с активным/последним Canvas; если холсты закрыты, создаётся представление. Подробности: [навигация](canvas-navigation.md), [стадии](notification-workspaces.md), [слои](layers.md).
