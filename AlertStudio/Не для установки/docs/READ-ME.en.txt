AlertStudio 0.2.1 — portable edition
Русский: READ-ME.ru.txt | English: READ-ME.en.txt

Windows 10/11 x64.

START
Extract the complete ZIP into a writable folder.
Run AlertStudio.exe. Node.js, pnpm and network access are not required.
Do not run inside the ZIP or remove DLLs, locales or resources.

DATA AND RELOCATION
On first launch the application creates Data beside the EXE:
Profile — interface settings and profile data;
Projects — projects created by the first Save;
Recovery — separate recovery drafts;
Extensions — installed trusted extensions;
Logs and CrashDumps — diagnostics.

To relocate, close the app and move the ENTIRE folder including Data.
The EXE alone does not work without the other files.
Save As and export can use external folders:
those files must be transferred separately.

UPDATES
Extract a new version separately. While both apps are closed, move your
Data into the new folder. Never replace personal Data with a clean ZIP.

FEATURES AND LIMITATIONS
Text, fog, stars, network; panels, history, basic stages and frame PNG.
Advanced stage animation, WebM/GIF, audio and integrations are absent.
A clean build contains no other user's projects, drafts or settings.
Development sources and tools are not required to run it.
Windows and C: to E: relocation were tested on one machine;
another physical computer and other operating systems were not tested.
There is no separate AlertStudio publisher signature; Windows may warn.
