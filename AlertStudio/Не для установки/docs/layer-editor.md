# Блокировка, Solo и метки

[Русский](<layer-editor.md>) · [English](<en/layer-editor.md>) · [Оглавление](<README.md>)

У выбранного слоя и в меню «Объект» доступны lock, Solo и цветовая метка. Значения входят в проект, сохраняются отдельно и поддерживают undo/redo. Они не являются локальными настройками панели.

Lock запрещает редактирование настроек/имени, drag, reorder, delete, reset и paste. Можно выбрать слой, скопировать его параметры, дублировать, менять видимость, Solo и метку. Дублирование не изменяет оригинал. Undo/redo остаётся доступным.

Можно включить Solo у нескольких слоёв. Рисуются только видимые Solo-слои; без Solo используется обычная видимость. «Снять Solo» — одна команда. Невидимый source может продолжать давать данные зависимому эффекту: скрытие отрисовки не разрывает граф.

Метка помогает организации и не меняет пиксели. Solo/visibility учитываются PNG, блокировка — только защитой редактирования. Optional editor marker отсутствует у старых объектов до явного изменения. Core атомарно отклоняет запрещённые команды. Проверки: layer-editor.test.ts и layer-editor-smoke.mjs.
