# Приоритетный план разработки

[Русский](<development-plan.md>) · [English](<en/development-plan.md>) · [Оглавление](<README.md>)

Это действующий порядок, согласованный с пользователем. Общий каталог из 218 идей не является очередью реализации. Развиваем собственные решения AlertStudio, а не копируем HTML. Расширенные стадии включены в план; базовая версия введена раньше, чтобы проверять будущие эффекты во всех четырёх областях.

1. Модель уведомления и совместимость — основа реализована; расширяется вместе со следующими этапами.
2. Основной эффект/появление/затухание/сборка — базовые длительности, fade, общий просмотр и сохранение реализованы.
3. Общая отрисовка — 13 blend modes, clip, hue/saturation/opacity и PNG реализованы.
4. Редактор — lock, multi-Solo, tags, search/changed/reset, scoped copy/paste и visible history реализованы.
5. Следующий участок: геометрия/сцена — угловые ручки, пропорции, grid snapping, направляющие, resize policies/anchor, масштабы подсистем/плотность, прозрачные поля, фоны/читаемость, frame step и показатели производительности.
6. Fog — несколько источников/веса, формы, готовые движения/структуры, двухцветный градиент, эрозия/пустоты.
7. Text — имя/сумма/сообщение, блоки, typography, wrap/fit, outline/shadow/backplate, тестовые уведомления.
8. Dark Base — отдельная область, связи с fog/text и относительная геометрия.
9. Stars — ring/bokeh, outline/no fill, угол, hue/saturation scatter, flying/выброс, velocity rotation, flow по fog, multi-source/weights.
10. Общие wind/vortex и collision/reactions с воспроизводимым seek.
11. Network — новые построения, окончания, curves/движущиеся точки; затем Edge Light, контур/нити/хвосты/искры.
12. Расширенные intro/outro/assembly — наследование, индивидуальные параметры, delays/keys/организация времени согласуются до реализации.
13. Пользовательские presets объектов/композиций/уведомлений, экспорт settings, перенос ссылок и переходы.
14. WebM — диапазоны/стадии, FPS, размер/качество/alpha, progress/cancel и детерминированный расчёт кадров.

Каждый этап заканчивается проверяемой функцией, save/open/undo/RU/EN и испытанием в четырёх областях. Звук, интеграции, AI и live OBS server не входят в ближайший объём и не запускаются по старым каталогам автоматически. Публикация — только по запросу с [portable/backup процедурой](portable.md).
