# Создание эффекта

[Русский](<creating-effect.md>) · [English](<en/creating-effect.md>) · [Оглавление](<README.md>)

1. Используйте examples/orbit и его отдельно собираемый manifest как рабочий образец.
2. Храните определения настроек отдельно от evaluate и от проектных значений. У всех подписей должны быть ru/en.
3. Нейтральный evaluate(values,time,context?) возвращает primitives. Seed и заданное время должны давать воспроизводимый результат; покадровая оценка не dispatch-ит команды проекта.
4. При необходимости зарегистрируйте специализированный Canvas renderer через sdk/canvas2d.ts с корректным dispose. Геометрию редактора задавайте через Effect.editor.
5. Соберите пакет, вычислите inventory, установите через «Правка → Расширения» и перезапустите. Проверьте создание двух независимых экземпляров, sources, seek, undo, save/open, PNG и отдельное окно.

Не импортируйте Electron/React/Canvas в core или sdk/index.ts. Отсутствующий renderer и недоступный source должны диагностироваться. SDK экспериментальный; [полный контракт](module-sdk.md).
