# Распределение звёзд по плотности

[Русский](<fog-density.md>) · [English](<en/fog-density.md>) · [Оглавление](<README.md>)

Cloud stars выбирает contour (legacy default) или density. Density bias 0–100% (default 60) усиливает сгущение в клубах; ноль всё ещё предпочитает плотные участки. Density fade 0–100% (default 100) ослабляет звёзды вне огибающей, у края и в просвете. При нуле fade отключён. Новые мелкие звёзды примера используют density; крупные — contour.

core/geometry/density.ts оценивает геометрическую огибающую клубов: центры/радиусы/веса, stretch/tilt, contour/softness и opening. Это не точная альфа шумовой текстуры: detail/contrast/RGB/brightness/общая opacity не входят в меру.

densityPlacement строит базовую карту 48×48 и cumulative probability, используя прежние seeded samples; кеш ограничен 16 картами. Seek не меняет базовую раскладку. Изменение seed/геометрии/весов намеренно пересобирает карту. Attachment добавляет движение клуба; текущая плотность отдельно регулирует alpha с учётом transforms поля.

centerCount использует центральную карту радиуса 0.42. Это число элементов, не гарантия видимых точек. Граничная ячейка может дать точку снаружи, которая затем затухнет. densityAlpha передаётся отдельно от twinkle; network учитывает минимум концов и может дополнительно маскировать середину ребра. См. [маску линий](line-mask.md).
