# Определения и значения настроек

[Русский](<settings-format.md>) · [English](<en/settings-format.md>) · [Оглавление](<README.md>)

Определения и сохранённые значения разделены. Встроенные *.setting.json содержат постоянный id, type, default, label.ru/en и, при необходимости, min/max/step/unit/animatable/group. Select задаёт options с value и двумя подписями. Value пока ограничен примитивами. Сохранённый settings/&lt;id&gt;.json содержит {value}.

Ajv проверяет проект, команды и внешние определения; дополнительные проверки отклоняют дубли ID, неверные defaults, диапазон, step, цвет и неизвестный select. Defaults копируются при создании. Неизвестные значения сохраняются; обновление definitions не должно молча переоформлять старый проект.

type:source хранит UUID либо пустую строку, sourceType задаёт тип эффекта. Core проверяет существование, тип, self-link и цикл при назначении. Удаление источника оставляет dangling link для диагностики и undo.

when задаёт {key,equals,and?:[{key,equals},...]}. Дополнительный массив плоский, от 1 до 8 условий; referenced keys проверяются. Поле видно, когда выполняются все условия. Отсутствующие значения читаются из defaults; скрытие контролов не удаляет сохранённые настройки.

Миграции, составные значения и keyframe tracks не реализованы. Для шаблонов добавления см. [создание объектов](object-creation.md), для поиска/сброса — [инструменты свойств](settings-tools.md).
