# Художественные параметры

[Русский](<appearance-controls.md>) · [English](<en/appearance-controls.md>) · [Оглавление](<README.md>)

| Область | Настройки и defaults |
|---|---|
| Fog | Контраст 0–300% (100), вытягивание 100–300% (100), наклон −180…180° (0) |
| Stars | Яркость бликов 0–100% (0), доля 0–100% (15), скорость 0–400% (100), длина лучей 1–12 (4) |
| Network | Dash 0–100 px (0), gap 0.1–100 (8), скорость −200…200 px/s (0), подложка 0–10 px/сторона (0), цвет #071223 |

Stretch/tilt fog меняют текстуры, но не центры/скорости клубов и привязанных звёзд. При detail 0 контраст не меняет равномерный клуб. Качество ограничивает поверхности; это не volumetric/GPU simulation.

Glints выбирают стабильную seeded-долю, не переставляя звёзды. Скорость 0 фиксирует фазу блика, но не останавливает движение/обычный twinkle. Лучи независимы от halo radius; общий alpha сохраняется.

Dash 0 даёт сплошную линию; знак скорости меняет направление. Подложка повторяет тот же dash/fade и рисуется перед цветной линией/glow. Пунктир начинается на каждом ребре отдельно, а не течёт по всему графу. Настройки не меняют topology или endpoint geometry. Все значения отдельно сохраняются, поддерживают RU/EN и undo; legacy defaults сохраняют старый вид.
