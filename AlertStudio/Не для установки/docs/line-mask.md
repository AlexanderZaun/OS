# Маска сети по туману

[Русский](<line-mask.md>) · [English](<en/line-mask.md>) · [Оглавление](<README.md>)

Network может учитывать плотность вдоль всего отрезка, включая просвет между видимыми концами. В новой сцене-примере включён density mask с влиянием 70%. Source fog берётся из runtime StarField.cloud источника stars, без отдельной проектной ссылки network → fog.

Настройки задают режим маски, влияние, шаг и порог. При влиянии 0 возвращается прежнее изображение. Маска учитывает transforms fog/stars и применяется к цветной линии, dash, glow и подложке. Потеря облачной области даёт missing-mask, не молчаливую новую привязку. ID/соседи/концы графа не меняются.

Используется геометрическая плотность, а не точная noise alpha. На ребро — до 32 отсчётов, на одну сеть/кадр — до 24000. При бюджете шаг увеличивается и показывается limit. Узкий просвет может быть пропущен; blur может заходить за прозрачный участок. Это плавная альфа, не геометрическое разрезание линий и не гарантия FPS.

Проверки: профиль середины при видимых концах, независимые transforms, budget/missing mask, dash/glow/underlay, сохранение/legacy defaults и пиксельный seek. См. [density](fog-density.md) и [topology](network-topology.md).
