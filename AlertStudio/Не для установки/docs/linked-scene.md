# Связанная сцена: туман → звёзды → сеть

[Русский](<linked-scene.md>) · [English](<en/linked-scene.md>) · [Оглавление](<README.md>)

«Файл → Сцена-пример» создаёт новую несохранённую композицию 1920×1080: четыре тумана, 1900 мелких/70 крупных звёзд и сеть крупных звёзд. Область 900×480; UUID генерируются заново. При dirty-проекте запрашивается замена. Три fog наследуют область первого, stars ссылаются на fog, сеть — на крупные stars.

Для ручной сборки добавьте fog, затем stars и назначьте fog source, затем network со stars source. Одна кнопка не добавляет зависимые объекты. Скрытие источника через visibility сохраняет вычисление; нулевой output даёт inactive-диагностику. Удалённый source оставляет ссылку для undo. Self/cycle/wrong-type назначения отклоняются.

Core вычисляет источник один раз на кадр независимо от z-order. Все Canvas используют общие Playback clocks; камеры независимы. Drag связанного поля меняет offset, а не координаты источника. Формат проекта 1 и версии эффектов 0.1.0 сохранены.

Network поддерживает segments/triangles/chains, текущие/устойчивые соседи, расстояние/число соседей, glow, dash/подложку и плотностную маску. Лимиты: до 1000 точек и 3000 рёбер; дополнительные бюджеты маски описаны отдельно. Обычный twinkle не перестраивает пары.

Несколько fog sources с весами, flying/flow, Dark Base и Edge Light ещё не реализованы. Pixel parity с HTML не требуется. Подробности: [область](shared-fog-region.md), [плотность](fog-density.md), [маска](line-mask.md), [топология](network-topology.md).
