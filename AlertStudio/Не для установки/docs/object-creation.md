# Добавление объектов

[Русский](<object-creation.md>) · [English](<en/object-creation.md>) · [Оглавление](<README.md>)

Каждая кнопка добавляет один объект, без автоматического создания источников. Туман, мелкие/крупные звёзды и сеть получают выбранные значения из modules/presets/cloud-network/layers.json: fog0, small, large, network. Текст и внешние эффекты используют свои правила.

Оба вида звёзд имеют type stars, но разные независимые настройки: 1900 мелких по плотности либо 70 крупных по контуру. Новые звёзды используют режим облака с пустым источником; новая сеть — пустой источник звёзд. До ручного назначения источника объект не рисуется, показывается диагностика. Для самостоятельных звёзд можно изменить режим поля.

«Связи с объектами» находятся первыми в свойствах, включая режимы, управляющие доступностью источников. При смене выбранного объекта прокрутка возвращается к началу. «Сцена-пример» отдельно создаёт семь связанных объектов: четыре тумана, два звёздных поля и сеть.

Bootstrap передаёт ObjectTemplate в Projects. add принимает необязательный template ID; без ID используется первый шаблон типа, без шаблона — defaults. Project-local ссылки очищаются. Значения копируются, а не связываются с шаблоном; один add — один undo. Старые объекты, неполные legacy values и defaults definitions не переоформляются при открытии или сохранении.
