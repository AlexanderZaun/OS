# Каталог и панели

[Русский](<catalog-and-panels.md>) · [English](<en/catalog-and-panels.md>) · [Оглавление](<README.md>)

Панель «Объекты» содержит разделы «Самостоятельные» и «Связанные». По умолчанию text/fog самостоятельные, мелкие/крупные stars и network требуют источник. «Разделы» позволяет пользователю менять распределение. Категория — только организация каталога: она не отменяет реальных требований эффекта. При несовпадении показывается пояснение.

Распределение хранится в localStorage профиля отдельно от проекта, синхронизируется между окнами и не меняет dirty/undo. В portable профиль находится в Data/Profile, поэтому переносится вместе с программой. Сброс раскладки не сбрасывает категории.

Панели перетаскиваются за вкладки, закрываются и восстанавливаются через «Окно». Необязательная панель «Панели» предлагает + для нового встроенного представления и ↗ для дополнительного окна. Она не открывается автоматически в новой раскладке. Отдельные окна не перезаписывают основную раскладку.

Каталог использует тот же SDK-компонент в основном и отдельном окне. Дополнительные Canvas имеют общие часы, но собственные камеры. Обновления старых раскладок добавляют каталог по marker, сохраняя намеренно закрытые пользователем панели после миграции. См. [добавление объектов](object-creation.md) и [компактность](compact-layout.md).
