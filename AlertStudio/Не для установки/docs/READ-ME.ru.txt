AlertStudio 0.2.1 — переносимая версия
Русский: READ-ME.ru.txt | English: READ-ME.en.txt

Windows 10/11 x64.

ЗАПУСК
Полностью распакуйте ZIP в доступную для записи папку.
Запустите AlertStudio.exe. Node.js, pnpm и интернет для работы не нужны.
Не запускайте программу изнутри ZIP; не удаляйте DLL, locales или resources.

ДАННЫЕ И ПЕРЕНОС
При первом запуске программа создаст Data рядом с EXE:
Profile — настройки интерфейса и данные профиля;
Projects — проекты при первом «Сохранить»;
Recovery — отдельные черновики восстановления;
Extensions — установленные доверенные расширения;
Logs и CrashDumps — диагностика.

Для переноса закройте приложение и перенесите ВСЮ папку вместе с Data.
Один EXE отдельно от остальных файлов не работает.
«Сохранить как» и экспорт могут использовать внешние папки:
эти файлы нужно перенести самостоятельно.

ОБНОВЛЕНИЕ
Распакуйте новую версию отдельно. При закрытых приложениях перенесите
свою Data в новую папку. Не заменяйте личную Data чистым архивом.

ВОЗМОЖНОСТИ И ОГРАНИЧЕНИЯ
Текст, туман, звёзды, сеть; панели, история, базовые стадии и PNG кадра.
Расширенная анимация стадий, WebM/GIF, звук и интеграции пока отсутствуют.
Чистая сборка не содержит чужих проектов, черновиков или настроек.
Исходники и инструменты разработки не нужны для запуска.
Проверены Windows и перенос между C: и E: на одной машине;
другой физический компьютер и другие ОС не проверены.
Отдельной подписи издателя AlertStudio нет; Windows может предупредить.

Готовые версии: https://github.com/AlexanderZaun/OS/releases/latest
Source code / Code → Download ZIP — исходники, а не готовая программа.
SHA-256 архива находится рядом с ним; это проверка целостности.
