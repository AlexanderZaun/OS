# Копирование параметров и история

[Русский](<copy-history.md>) · [English](<en/copy-history.md>) · [Оглавление](<README.md>)

«Объект → Копировать параметры» сохраняет неизменяемый снимок известных настроек и оформления во внутренний буфер, общий для окон. Это не Windows clipboard. Копирование из locked-слоя разрешено и не меняет dirty, autosave или undo.

«Вставить параметры…» предлагает области. Effect settings требуют совпадения type и точной версии; скрытые известные значения включены, неизвестные ключи получателя сохранены. Координаты, sources и управляющие режимы по умолчанию исключены и включаются отдельно. Неверная ссылка отклоняет всю вставку. Оформление можно переносить между типами; отсутствие стиля донора означает обычные defaults. Имя, UUID, visibility, lock, Solo и tag не копируются.

Paste защищён lock и revision, выполняется атомарно одним undo. No-op/отмена не создают шаг. Диалог закрывается при смене целевого состояния. Open/New/Recovery очищают буфер; перенос между сеансами/проектами не реализован.

«Правка → История действий» открывает панель, первоначально вкладкой у свойств. Доступны перемещение, дополнительные представления и отдельное окно. Максимум 100 шагов, свежие сверху. Строка возвращает состояние после выбранного действия; начало означает самое раннее ещё доступное состояние. Переход назад/вперёд публикует один snapshot, не исполняет записанные команды.

Новая правка после undo отбрасывает redo-ветку. Выбор, камера, поиск, копирование, playback и экспорт не создают шагов; настройки стадий создают. Save сохраняет историю в памяти, но не записывает её на диск. Open/New/Recovery начинают историю заново. Git backup tags и файловые ревизии — отдельные механизмы.
