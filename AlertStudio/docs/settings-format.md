# Настройки

Самостоятельное определение — `*.setting.json`: постоянный id, type (`number/string/color`), default, min/max, unit, animatable, label.ru/en. Типы проверяются TypeScript для встроенного кода; проект, команды и внешние definitions — Ajv во время загрузки. Дополнительно проверяются дубли ID, тип/диапазон default и цвет. Ключи переводов вместо inline label — незавершённая работа.

Сохранённое значение — отдельный `settings/<id>.json` с `{value: ...}`. Defaults копируются при создании. Неизвестные параметры сохраняются при повторном сохранении; отсутствующий эффект не удаляет данные. Составные значения, keyframe tracks, миграции и версии поведения ещё не реализованы; текущий Value ограничен примитивами.
