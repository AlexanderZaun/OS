# Создание эффекта

Рабочий внешний пример: examples/orbit. Определения настроек лежат в отдельных JSON; `evaluate(values,time)` возвращает обычные примитивы. Время — секунды, значения не меняются внутри evaluate. Два экземпляра получают независимые скопированные defaults. Panel properties строит controls по определениям.

Первая реализация SDK умеет только text/rect. Это проверка загрузчика и жизненного цикла модели; она не подменяет перенос сложного тумана. Специализированный Canvas renderer, simulation state и экспортный host будут следующими расширениями контракта. Не помещайте Canvas/Pixi-классы в values.
