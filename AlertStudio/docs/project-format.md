# Папка проекта v1 (экспериментальная)

project.json содержит только id/name/format/revision/scene. Данные лежат в `revisions/<uuid>/scenes/main/`: scene.json содержит ID объектов; `settings/width.json`, height.json, background.json — независимые значения сцены. `objects/<id>/object.json` содержит metadata и settingIds; `objects/<id>/settings/<key>.json` — значение. `revisions/<uuid>/modules.lock.json` записывает точные версии эффектов и SDK. Ссылки типов объектов должны присутствовать в lock. Версия пакета, несовпадающая с lock, не используется до явной миграции; сохранение неизвестных данных остаётся доступным.

Ревизии неизменяемы. Save сначала создаёт целое новое дерево, затем меняет единственный project.json через rename временного индекса. Это не атомарная последовательность rename множества файлов: опубликован только один указатель, старое дерево остаётся пригодным. Прерывание до переключения оставляет старый проект, незавершённые неиспользуемые ревизии инертны. Fault injection тест проверяет это. Файлы проверяются по типам, ID, относительным ссылкам и соответствию ID metadata.

Это восстановление после ошибки процесса, не доказанная гарантия при физическом отключении питания: fsync, повреждение индекса и резервный индекс пока не покрыты. Не удаляйте старые ревизии автоматически. Сбор мусора, журнал диагностики, автосохранение отдельно от explicit Save, блокировка папки между процессами, assets и stage tracks ещё не реализованы. Папка для Save выбирается пользователем; избегайте совместной записи несколькими экземплярами до реализации блокировки.

Неизвестные эффекты сохраняются и отмечаются в Properties; на холсте отсутствующий effect пока не рисует видимую рамку-заглушку. Открытие папки читает только данные, пакетный код из проекта не выполняется.
