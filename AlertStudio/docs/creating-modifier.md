# Модификаторы — следующий этап

Рабочих модификаторов в SDK 0.1 пока нет. Первый запланирован — пульсация прозрачности: отдельные setting definitions и значения экземпляра, enable/disable/remove через команды с undo. Вычисленный коэффициент умножается на базовую прозрачность, затем appearance коэффициент, clamp применяется после объявленных операций. Значение базы не изменяется при проигрывании.

До реализации нужно определить повторяемость, порядок блоков и фазу обработки. Не регистрируйте формальную заглушку как рабочий modifier. Проверки: совместные блоки, порядок, отключение, сериализация и миграция.
