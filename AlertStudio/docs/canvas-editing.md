# Выбор и перемещение объектов

Левая кнопка выбирает верхний объект под курсором, перетаскивание перемещает его в координатах сцены. Поддержаны встроенные text, fog и stars. Для полей проверяется вся область, включая прозрачные участки; для текста измеряется ширина строк с тем же шрифтом, что в renderer. Учитывается поворот области. Пустой щелчок снимает выделение. Рамка — DOM overlay, в пиксели Canvas не попадает.

Эффект может предоставить optional neutral `Effect.editor`: position с ключами x/y и bounds(values, measureText). Измеритель текста передаётся UI и возвращает число; DOM не попадает в модель/SDK index. Внешний loader исключает callback editor из декларативного определения, отправляемого main. Модули без editor остаются доступны в Layers/Properties, но не выбираются на холсте.

Жест хранит исходный объект, масштаб и revision. Pointer moves меняют только локальный preview; на отпускание отправляется одна команда patch с обеими координатами и исходной revision. Core проверяет все поля до изменения модели и отклоняет устаревшую revision; успешный patch выбирает объект и создаёт одну запись undo. Значения ограничиваются min/max и округляются по step (по умолчанию для перетаскивания 1px).

Esc, pointer cancellation, потеря захвата/фокуса, изменение authoritative revision, изменение геометрии камеры и операция проекта отменяют preview. Масштаб жеста измеряется по фактическому DOM-прямоугольнику Canvas. Изменение из другого окна не затирается старым жестом. Во время object drag wheel и начало другого pan заблокированы; вне жеста Space/middle mouse сохраняют навигацию камеры. Touch пока перемещает камеру, а не объект.

Проверено в Electron: выбор пустоты и повёрнутого поля, preview без изменения snapshot, drag при 50%/200%, один undo/redo, Esc, concurrent edit, синхронизация Properties отдельного окна, UI 900×650/1920×1080. Evidence: artifacts/editing-ui-results.json и editing screenshots.

Ручек изменения размера/поворота, snapping, множественного выбора, блокировки слоёв и выбора сквозь перекрывающиеся области пока нет. Перемещение объекта выполняется при отпускании мыши; Properties во время жеста показывают подтверждённое состояние. Блок 6 плана остаётся частично выполненным.
