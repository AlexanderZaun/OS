# Добавление объектов с оформлением сцены-примера

Кнопки «Туман +», «Мелкие звёзды +», «Крупные звёзды +» и «Сеть звёзд +» добавляют по одному объекту. Оформление берётся из `modules/presets/cloud-network/layers.json`: fog0, small, large и network соответственно. Туман — самостоятельный первый слой примера, а не вся четырёхслойная композиция. Текст и внешние эффекты сохраняют прежние правила создания.

Связанные объекты автоматически не добавляются. Новые звёзды находятся в режиме «По облаку», источник тумана пуст; у сети пуст источник звёзд. До выбора источника такой объект не рисуется и холст показывает диагностику связи. Выбор доступен в начале свойств, в разделе «Связи с объектами». Для самостоятельных звёзд можно переключить «Режим поля». Режим общей области тумана также находится сверху; источник области появляется при выборе режима «По другому туману». Смена выделения возвращает панель к началу. Настройки связей остаются доступными в отдельных окнах свойств.

Оба варианта звёзд используют один существующий тип `stars`, но копируют разные параметры: 1900 мелких звёзд с распределением по плотности или 70 крупных с распределением по контуру. Значения экземпляров независимы. Прежняя сцена-пример по-прежнему создаёт семь связанных объектов.

`contracts/object-template.ts` описывает данные шаблона создания; `object-templates.ts` получает выбранные значения из сцены-примера и очищает ссылки `$...`. Bootstrap передаёт шаблоны авторитетной службе Projects. Команда `add` принимает необязательный ID `template`; при отсутствии ID берётся первый шаблон данного типа, а без шаблонов — defaults эффекта. Создание записывает отдельные эффективные значения в объект, а не ссылку на шаблон. Один объект — одно действие Undo/Redo. Несуществующий или чужой типу шаблон отклоняется без изменения истории.

Определения настроек, их defaults для старых неполных данных, версии эффектов, формулы evaluate и формат проекта не менялись. Открытие, сохранение и воспроизведение существующих объектов не применяют шаблоны создания. Последующие изменения шаблонов не переписывают уже созданные объекты.

Проверки: `tests/object-templates.test.ts` и `tests/object-templates-smoke.mjs` — значения из примера, один объект, пустые/ручные источники, два варианта звёзд, независимость дубликатов, seek, Undo/Redo, folder roundtrip, сохранность legacy data, отдельные свойства, RU/EN и 900×650/1920×1080. Условия UI-снимков object-templates-compact/1080.png: сцена 1920×1080, прозрачный фон, Canvas2D, normal fog quality, t=6s, fog seed42, small seed8197, large seed8201; обе звёздные системы вручную связаны с единственным fog0, сеть — с крупными звёздами.
