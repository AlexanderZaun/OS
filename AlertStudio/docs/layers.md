# Управление слоями

Панель «Слои» показывает объекты в порядке переднего плана: верхняя строка рисуется поверх нижних. Источники эффектов вычисляются отдельно от порядка отрисовки, поэтому перестановка тумана, звёзд и сети сохраняет связи по UUID.

## Действия

- Выберите строку для редактирования свойств. Галочка управляет видимостью.
- Нажмите **«Переименовать слой»** или **F2**, когда фокус находится на кнопке имени слоя. Имя сразу выделяется в общем диалоге. Enter в поле подтверждает, Escape отменяет. Пустые имена запрещены; предел 200 символов, пробелы по краям удаляются.
- Перетащите слой за ручку **⠿** на другую строку. Верхняя половина цели вставляет слой выше неё, нижняя — ниже. Акцентная линия показывает место вставки. У краёв списка есть прокрутка при drag-over.
- Используйте **«Слой выше/ниже»** для одного шага, **«На самый верх/низ»** — для переноса к границе всей сцены. Граничные действия отключены, если слой уже на месте. Эти кнопки доступны с клавиатуры.
- Поиск находит имя, локализованный тип, внутренний ID типа и UUID. Фильтр по типу сочетается с поиском. Пустой результат предлагает сброс фильтров. Фильтрация не изменяет проект, его видимость, историю или выбранный объект.

Перенос в отфильтрованном списке вставляет относительно указанной цели в полном порядке сцены. Относительный порядок всех остальных слоёв сохраняется. Верх/низ всегда относятся ко всей сцене.

## История и окна

Переименование или перенос — одно изменение и один шаг отмены. Настройки эффектов, UUID и ссылки источников не переписываются. Изменения отражаются в других экземплярах панели и отдельных окнах, записываются в обычный многофайловый проект и черновик восстановления.

Перетаскивание привязано к ревизии проекта: изменение модели во время жеста отменяет его, а main отклоняет устаревшую команду. Перенос между окнами через drag-and-drop не реализован; используйте панель в одном окне. Поиск и фильтр локальны для каждого экземпляра панели, сбрасываются при смене проекта и не сохраняются в файл проекта.

После удаления или отмены добавления выбранный ID больше не может указывать на отсутствующий объект. Восстановление удалённого объекта через Undo возвращает объект, но не выбирает его автоматически.

Шапка и действия отделены от прокрутки списка. При малой высоте подсказка/имя проекта скрываются, а действия располагаются в одной строке с горизонтальной прокруткой. При совсем низкой панели счётчик скрывается, оставляя место строкам. Новые диалоги и контролы используют общие theme tokens и RU/EN. Группы, блокировка, solo и множественный выбор остаются следующими этапами.
