# Поиск, изменения и сброс параметров

Кнопка ⌕ рядом с именем объекта в «Свойствах» раскрывает поиск, переключатель «Изм.» со счётчиком и «Сброс…». По умолчанию инструменты свёрнуты, чтобы выбор источника оставался виден в узкой панели. Повторное нажатие сворачивает инструменты и очищает запрос/фильтр. Они не расширяют минимальную ширину панели. Связи с объектами остаются первым разделом параметров; затем идут оформление слоя и группы эффекта.

Поиск работает по русским и английским названиям, ID параметра, названиям групп и вариантам выбора независимо от языка интерфейса. Регистр и различие е/ё не мешают поиску; несколько слов должны встречаться в метаданных параметра. Единицы измерения не участвуют: например, X в запросе Position X не должно находить Position Y только из-за px. Поиск не ищет в пользовательском тексте уведомления и именах источников. Пустой результат предлагает очистить поиск и фильтр. Escape в поисковой строке очищает запрос.

Обычный список показывает только доступные в текущем режиме параметры. Поиск и фильтр изменений находят также скрытые поля: они показаны неактивными с подписью «Доступно при…», рядом включены управляющие их доступностью параметры, включая вложенные условия. Условия AND учитываются вместе. Можно переключить нужный режим и затем отредактировать найденное поле. Сброс изменённого скрытого параметра доступен без изменения режима. Сам поиск/фильтр не меняет проект, dirty, историю или состояние другого окна; после смены объекта поиск начинается заново. Изменения значений общие для всех окон.

Звёздочка у подписи и счётчик обозначают **отличие от базового значения эффекта**, а не отличие от сохранённого файла. База берётся из определения параметра установленной версии эффекта. Оформление сравнивается с обычным смешиванием, выключенной обрезкой, оттенком0°, насыщенностью100% и непрозрачностью100%. Значения сцены-примера/шаблонов могут отличаться от этой базы сразу после добавления — это ожидаемо и подписано в справке сброса. Поиск не влияет на общий счётчик. Отсутствующее сохранённое значение, использующее базу, не считается изменением. Неизвестные параметры недоступного модуля не сравниваются с неподходящей версией.

Кнопка ↶ у изменённого параметра сбрасывает только его, одним действием undo. «Сброс…» открывает общий Dialog с двумя независимыми действиями:

- «Сбросить эффект» возвращает все известные параметры эффекта, включая скрытые, положение и ссылки на источники. Пустая базовая ссылка отключает связь. Неизвестные сохранённые ключи остаются нетронутыми.
- «Сбросить оформление» возвращает только общие параметры оформления слоя. Параметры эффекта остаются прежними; optional оформление удаляется из модели, если до сброса оно отличалось от базы.

Каждый полный сброс — одно действие истории. Имя, visibility, блокировка, Solo и цветовая метка не сбрасываются. Поисковый запрос не ограничивает полный сброс; это явно написано в диалоге. Число на каждой кнопке — количество изменённых параметров соответствующей области, включая скрытые. Отмена/закрытие диалога ничего не меняет. Диалог закрывается при смене ревизии, выборе другого объекта, блокировке или общей операции проекта, чтобы не применить старое подтверждение к новому состоянию.

Блокировка запрещает отдельные и полные сбросы и проверяется в core. Поиск при этом доступен. Отсутствующий или неподходящий эффект нельзя сбросить; общие параметры оформления остаются независимыми от него. Команда `settings-reset` содержит id, scope=effect|layer, key=ID|null и ожидаемую revision. Неверные ключи, scope и устаревшая ревизия отклоняются атомарно. Сброс неизменённых значений не создаёт запись истории и не переписывает legacy defaults. Значения сохраняются в прежних отдельных файлах; новый формат хранения и данные поиска не вводятся.

Копирование параметров и видимая история реализованы следующим продолжением; см. copy-history.md. Кнопки Copy/Paste находятся и в раскрываемых инструментах свойств.
