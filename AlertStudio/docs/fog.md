# Собственный процедурный туман

Обновление 17.10.2026: 36 definitions. Добавлена [наследуемая область нескольких fog](shared-fog-region.md); в сцене-примере три слоя используют область первого. Описания предыдущих этапов ниже сохранены.

Текущее обновление: 30 definitions, cloud shape/roughness, area/rim/mixed, регулируемое число клубов, brightness/phase, elliptical opening и draft/normal/high quality. Добавлены контраст текстуры и вытягивание/наклон клубов: [настройки оформления](appearance-controls.md). Публикуются координаты/скорости клубов для звёзд. [Связанная сцена](linked-scene.md). Ниже описан исходный самостоятельный режим, сохранённый по умолчанию.

По уточнению пользователя эффект проектируется под AlertStudio. Исходный HTML — визуальный ориентир; совпадение его кадров и повторение алгоритма не являются критерием приёмки нового эффекта.

Модель `modules/effects/fog/src/model.ts` создаёт нейтральные данные: 36 клубов с фиксированными случайными параметрами, положением и весом. Ветер и завихрения — периодические функции времени без накопления состояния. При скорости 100% период равен настройке «Период движения»; при другой скорости фактический период масштабируется обратно пропорционально скорости. Направление ветра задаёт ось колебательного дрейфа; однонаправленная адвекция пока не реализована.

Definitions хранятся отдельно в `settings/*.setting.json`. Плотность управляет весом клубов, непрозрачность — альфой всего слоя. Нулевое значение любого из этих параметров возвращает пустой кадр. Параметры не привязаны к фиксированным fog1–fog4: любой UUID получает собственные значения, историю и renderer.

Canvas2D renderer строит 96×96 текстуру по трём масштабам шума, собирает её на локальную поверхность 384×384 и применяет прозрачную маску. Маска кешируется по форме/мягкости, текстура по зерну/детализации/цвету, неизменившийся кадр повторно не собирается. Размер поверхностей ограничен и не зависит от сцены. Backend вызывает dispose при исчезновении объекта из кадра и при закрытии панели.

Ограничения: даже high quality ограничен поверхностью 768×768, дальнейшее увеличение смягчает детали; GPU, ключей и однонаправленного потока нет. Есть один встроенный preset композиции и общие runtime clocks; библиотеки пресетов нет. Проверка не доказывает высокую производительность при произвольном числе слоёв.

Проверки: `tests/fog.test.ts` — детерминированность/период, нулевая плотность, независимые копии, validation, history и folder roundtrip. `tests/fog-smoke.mjs` — реальный Electron, совпадение пикселей при seek 6→12→6, прозрачность, две копии, select, RU/EN, save/open и screenshots. `tests/fog-render-harness.ts` — настоящий backend, освобождение удалённого объекта и завершение backend.

Evidence: `artifacts/fog-ui-results.json`, screenshots `fog-editor-compact.png` и `fog-editor-1080.png`. Замер harness — 30 синхронных кадров одного fog на Canvas 1920×1080, без React, ожидания display/vsync и записи видео; это время вызова render, не FPS приложения. Длительная нагрузка и пиковая память не проверены.
