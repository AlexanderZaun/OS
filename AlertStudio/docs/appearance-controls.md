# Художественные настройки тумана, звёзд и линий

Продолжение 16.10.2026. Откройте «Сцену-пример», выберите нужный слой в «Слоях» и измените параметры в «Свойствах». Используется существующий интерфейс, тема и RU/EN. Значения сохраняются по одному на файл, доступны undo/redo; версии эффектов 0.1.0 и format проекта 1 сохраняются. Новые настройки по умолчанию не меняют изображение старого проекта.

## Туман — группа «Вид»

* **Контраст текстуры**: 0–300%, default 100%. Усиливает различие плотных и прозрачных деталей процедурного шума; яркость цвета регулируется отдельно. При детализации 0% контраст не влияет на равномерный клуб.
* **Вытягивание клубов**: 100–300%, default 100%. Каждая текстура растягивается вдоль одной оси и сжимается вдоль другой с сохранением площади. Для более тонких клубов попробуйте 160–200%.
* **Наклон клубов**: −180…180°, default 0°. Угол относительно направления от центра облака к базовому положению клубка. 90° располагает вытянутые клубы вдоль кольца. При вытягивании 100% круглая оболочка не вытягивается, ветка вращения не используется.

Трансформация меняет рисунок клубов, а не их центры, скорости или общую маску. Привязанные звёзды сохраняют свои координаты. Поверхности остаются ограничены настройкой качества; это не полноценная объёмная или GPU симуляция. Сильное вытягивание может обрезаться внешней маской, что соответствует выбранной области.

## Звёзды — группа «Блики»

* **Яркость бликов**: 0–100%, default 0% (выключено).
* **Доля звёзд с бликами**: 0–100%, default 15%. Стабильная выборка из существующего seed; изменение доли не переставляет звёзды.
* **Скорость бликов**: 0–400%, default 100%. 0% фиксирует фазу блика; движение и обычное мерцание продолжаются независимо.
* **Длина лучей блика**: 1–12 размеров ядра, default 4. Для крупных квадратных звёзд попробуйте яркость 85%, долю 40%, длину 7.

Короткая аналитическая вспышка рисует четыре луча поверх выбранной формы ядра. Цвет лучей соответствует цвету поля с белым центром; общий opacity и alpha звезды продолжают действовать. Длина не зависит от радиуса ореола. Все элементы одного поля используют одну дополнительную текстуру 64×64, создаваемую при первом видимом блике и освобождаемую вместе с renderer. Длинные исторические следы остаются отдельной будущей задачей.

## Сеть звёзд — группа «Линии»

* **Длина штриха**: 0–100 px, default 0 (сплошные линии).
* **Промежуток штрихов**: 0.1–100 px, default 8.
* **Скорость пунктира**: −200…200 px/s, default 0. Знак меняет направление, ноль останавливает движение. Значения заданы в координатах сцены и масштабируются вместе с холстом.
* **Толщина подложки**: 0–10 px с каждой стороны, default 0 (выключена).
* **Цвет подложки**: default #071223. Подложка повторяет тот же пунктир и затухание ребра; рисуется перед цветной линией и её glow.

Например, длина 12, промежуток 8, скорость −13 и подложка 0.5 дают движущийся пунктир с тёмной окантовкой. Настройки оформления не меняют поиск соседей, ID рёбер, лимиты и конечные точки сети. Пунктир начинается заново на каждом ребре; это не единый поток по всему графу.

## Проверки

Для точного сравнения кеша тест создаёт readback canvas с willReadFrequently до первого draw. Иначе частое getImageData заставляет Chromium менять путь GPU/CPU, что может давать разные младшие значения каналов. Обычный preview продолжает использовать стандартный Canvas context. Индикаторы времени после паузы в двух окнах проверяются по подтверждённому main snapshot, после обновления обоих окон.

Проверяются независимость геометрии от оформления, стабильность seed при изменении количества, выключение/заморозка бликов, отрицательная скорость пунктира и folder roundtrip. Electron проверяет новые RU controls, сохранение/открытие, 6→12→6, cache enable/change/disable для всех трёх renderer и различие пикселей при анимации. Скриншоты просмотрены при 1920×1080 и 900×650.
