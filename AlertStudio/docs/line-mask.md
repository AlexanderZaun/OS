# Линии по плотности тумана

Обновление 17.10.2026. Сеть может учитывать плотность тумана вдоль всего отрезка. Пустые участки и просвет ослабляют середину линии даже при видимых концах. В новой «Сцене-примере» включена маска с влиянием 70%; существующие проекты без новых значений сохраняют вариант без маски.

## Управление

Выберите «Сеть крупных звёзд» → «Свойства» → «Линии в тумане».

* **Маска линий**: «Без маски» (default) или «По плотности тумана».
* **Влияние маски**: 0–100%, default 100. При 100 пустые участки полностью прозрачны; промежуточное значение сохраняет часть линии вне облака. Ноль возвращает отрисовку без маски.
* **Шаг проверки линии**: 4–64 px сцены, default 12. Меньший шаг точнее описывает мелкие просветы и требует больше расчётов.
* **Плотность для полной видимости**: 1–100%, default 12. Выше этого уровня линия сохраняет исходную прозрачность; ниже плавно затухает.

Дополнительные поля показываются только при включённой маске; их значения сохраняются при переключении. Настройки сети теперь представлены 20 отдельными definitions. Формат проекта 1 и версия network 0.1.0 сохраняются. Значения проекта по-прежнему записываются в отдельные setting files.

## Источник и отрисовка

Используется именно fog, с которым связано выбранное поле stars. Дополнительный источник маски вручную выбирать не нужно. Связь доступна и для распределения звёзд по контуру, и для распределения по плотности. Независимое поле stars не содержит области тумана: при включённой маске с ненулевым влиянием сеть не рисуется, а холст сообщает, что нужно связать поле звёзд с туманом. Выключение маски/влияние 0 возвращает обычную сеть.

StarField.cloud передаёт размеры и текущую огибающую fog, а его мировое смещение задаётся относительно центра stars. Это runtime данные, не новые исполняемые значения проекта. Смещение, относительный масштаб/поворот звёзд и унаследованная область fog учитываются при переводе каждого положения на линии в координаты источника.

Поиск соседей, ID рёбер и конечные точки сохраняются. NetworkFrame.edges[].samples содержит нормализованные t/alpha. Canvas renderer рисует градиент прозрачности вдоль ребра; тот же профиль действует на цветную подложку и пунктир, включая его движение. Свечение использует прозрачность этого же stroke. Полностью прозрачные рёбра пропускаются при отрисовке, оставаясь в графе.

Маска дополнительно умножает прежние opacity, затухание по длине и densityAlpha концов. Обычное мерцание звёзд не меняет граф. Скрытый fog продолжает вычисляться; нулевой output/удалённые источники по-прежнему диагностируются системой зависимостей.

## Ограничения

Используется геометрическая плотность клубов, а не точный шумовой alpha renderer. Цвет/brightness/общая opacity fog не входят в меру; см. fog-density.md. Это плавное затухание, а не точное геометрическое разрезание отрезков.

На ребро приходится не более 32 отсчётов, суммарно не более 24000 на одну сеть и кадр. При достижении бюджета шаг увеличивается, выводится сообщение об ограничении сети. Положение/ID рёбер остаются прежними. Просвет уже шага может быть пропущен; blur свечения может немного заходить за прозрачный участок. Для более точной формы уменьшайте шаг, учитывая предел. Бюджет ограничивает работу, но не гарантирует заданный FPS на максимальной сцене.

## Проверки

38 behavior tests, включая четыре новых: затухание середины без изменения графа, независимые transform fog/stars, отсутствие маски и бюджет большой сети, сохранение и старые defaults. Electron проверяет conditional RU/EN controls, потерю fog связи, save/open, перемотку 6→12→6 и реальную прозрачность центрального пикселя при видимых концах. Дополнительно проверены glow/outline/dash и возврат исходных пикселей при влиянии 0.

Финально все девять Electron scripts прошли единым прогоном. Новый pixel harness использует synthetic source для изолированной проверки просвета; изображение общей сцены и UI также проверены. Для baseline после последней настройки тест дожидается её принятия UI и двух RAF, не только ответа main. Прежнее ограничение холодного readback описано в fog-density.md.

Снимки просмотрены в 1920×1080 и 900×650. Артефакты: artifacts/line-mask-ui-results.json, artifacts/screenshots/line-mask-1080.png и line-mask-compact.png. Отчёт также содержит 30 синхронных evaluate/draw кадров сцены 4 fog + 1900/70 stars + network после прогрева; он не измеряет FPS всей UI.
