# Оформление слоёв и PNG

При активном Solo в композицию и PNG входят только видимые Solo-слои. Нижний слой для обрезки также выбирается из допущенных к рисованию; для изолированного просмотра обрезанного слоя включите Solo и у его маски. См. layer-editor.md.

Общие параметры находятся в свойствах объекта в разделе «Оформление слоя», после связей с источниками и перед параметрами эффекта. Раздел свёрнут по умолчанию. Доступны 13 режимов смешивания: обычный, умножение, экран, перекрытие, затемнение, осветление, осветление/затемнение основы, жёсткий/мягкий свет, разница, исключение и сложение. Непрозрачность — 0–100%, оттенок — −180…180°, насыщенность — 0–200%. Числа применяются по Enter или потере фокуса; Escape возвращает сохранённое значение, неверный ввод помечается и не попадает в проект.

Обрезка использует альфа-канал ближайшего **видимого** слоя ниже по порядку рисования, включая его непрозрачность и уже применённую обрезку. Скрытые слои пропускаются; видимый слой без изображения даёт пустую маску. Без нижнего слоя результат прозрачный. Обрезанный слой может служить маской следующему. Смешивание с общей композицией не меняет его собственную маску. Это отдельная операция оформления, не связь тумана/звёзд/сети: вычисление источника, его геометрия и плотность остаются прежними.

Порядок: эффект рисует собственную группу → оттенок/насыщенность и общая непрозрачность → обрезка → смешивание с нижними слоями → прозрачность стадии уведомления один раз для всей композиции. Обычные слои без изменений используют прежнюю прямую отрисовку. При оформлении используются три переиспользуемых поверхности размера сцены, а для затухания — дополнительная общая поверхность. Эти операции расходуют память и время пропорционально размеру сцены и числу слоёв; ускорение GPU и нагрузочная проверка больших композиций пока не выполнены.

«Файл → Экспорт кадра в PNG…» фиксирует проект, текущую область и точное время общих часов до открытия системного выбора файла. Отдельный Canvas той же системы отрисовки формирует изображение в разрешении сцены. Учитываются все видимые слои, оформление и стадия. Масштаб/прокрутка холста, рамка выделения, подсказки, шахматка и цвет фона предпросмотра не входят в PNG. Прозрачность сохраняется; это экспорт кадра, не экспорт анимации. Во время воспроизведения сохраняется момент вызова команды, а не момент подтверждения системного окна. Объекты с отсутствующими источниками/модулями остаются такими же пустыми, как в предпросмотре.

PNG не заменяет сохранение проекта, не меняет dirty/history и не снимает необходимость явного Save. Отмена системного окна не пишет файл. Запись идёт во временный файл рядом с выбранным, с sync и последующим rename; ошибка отображается, старый файл не заменяется до завершения записи. В main проверяются PNG-сигнатура, размер, границы разрешения и декодирование. Свойства объектов сохраняются в многофайловом проекте, включая Recovery и undo/redo.

`SceneObject.layer` — optional `version:1` со значениями `blend`, `clip`, `hue`, `saturation`, `opacity`. Определения и валидация находятся в core/scene/layer-style.ts, не внутри настроек эффекта. На диске object.json содержит маркер `layer:1`, а каждое значение — собственный `objects/<id>/layer/settings/<key>.json`. Старые объекты без маркера сохраняются без добавления defaults; пропавшее/невалидное значение новой ревизии приводит к проверке резервной ревизии.

SDK остаётся экспериментальным 0.1: `RenderBackend.render(primitives, opacity?, layers?)`, где `RenderLayer` содержит id и optional style. Старые вызовы без третьего аргумента работают как прежде. `evaluateScene` возвращает отдельный список видимых слоёв, включая пустые; стили не дописываются в primitives, выдаваемые источникам. Внешний renderer эффекта рисует в предоставленный Canvas-контекст и автоматически участвует в оформлении и PNG.
