Готовая переносимая версия AlertStudio для **Windows 10/11 x64**.

Скачайте **AlertStudio-0.2.0-Windows-x64.zip** из Assets ниже, полностью распакуйте и запустите **AlertStudio.exe**. Node.js, pnpm и установка зависимостей не нужны. Архивы «Source code» предназначены для разработки.

- Программа работает офлайн и создаёт Data рядом с EXE. Первое «Сохранить» записывает проект в Data/Projects.
- Для переноса между дисками/компьютерами закройте программу и перенесите всю распакованную папку вместе с Data.
- В архиве нет личных проектов, настроек, бэкапов, node_modules и результатов тестов. Сохранены необходимые библиотеки и лицензии.
- В выпуск включены компактные перемещаемые панели, четыре области уведомления, оформление слоёв, PNG, блокировка/Solo/метки, поиск и сброс настроек, копирование параметров и история действий.

Проверено: типы, архитектурные границы, 81 функциональный тест, 22 сценария Electron; отдельная проверка EXE из ZIP с переносом с C: на E:, сохранением профиля, проекта, черновика и расширения, окна 900×650 и 1920×1080. Проверка на другом физическом компьютере не выполнялась.

SHA-256 архива находится в отдельном файле Assets. Сборка не имеет отдельной подписи издателя AlertStudio; Windows может показать предупреждение. Требуется доступная для записи папка. Файлы, сохранённые за её пределами, переносите отдельно. Для обновления распакуйте новую версию отдельно и перенесите свою Data при закрытой программе.
