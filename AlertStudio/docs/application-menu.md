# Меню приложения

В основном окне доступны восемь меню: Файл, Правка, Сцена, Объект, Воспроизведение, Вид, Окно, Справка. Длинная полоса общих кнопок удалена. Каталог, слои и свойства остаются независимыми Dockview-панелями. Быстрые инструменты камеры и воспроизведения остаются у холста.

## Действия

- Файл: новый проект, сцена-пример, открытие, сохранение, сохранение как, черновики восстановления.
- Правка: отмена, повтор, расширения, выбор RU/EN.
- Сцена: сведения о текущих размерах, фоне, количестве объектов и папке; вписывание сцены. Изменение размеров существующего проекта пока не реализовано.
- Объект: показать каталог, переименовать, дублировать, изменить видимость, удалить, изменить порядок. Используются существующие Commands и общая история. Новые объекты добавляются через каталог с сохранением его разделов и шаблонов.
- Воспроизведение: запуск/пауза, переход к нулю, повтор, скорости 0.25/0.5/1/2. Используются общие часы main; это не редактирование стадий появления или затухания.
- Вид: вписать сцену/выбранное, 100%, центр, увеличение/уменьшение, рука. Команда применяется к активному холсту; если активна другая панель, используется последний холст, с которым взаимодействовали, либо первый доступный. Если все холсты закрыты, создаётся новое представление и выполняется команда.
- Окно: показать существующую панель или восстановить закрытую; добавить представление; открыть дополнительное окно; сбросить раскладку. «Показать» не создаёт дубликаты.
- Справка: действующие сочетания клавиш и сведения о версии с текущими ограничениями.

Панель «Панели» остаётся необязательным перемещаемым быстрым доступом. Новая или сброшенная раскладка её не открывает автоматически. Сохранённые раскладки, включая уже открытое управление панелями, восстанавливаются без изменения. Каталог объектов по-прежнему мигрирует по прежним правилам.

## Доступность и адаптация

MenuBar использует семантику menubar/menu/menuitem/menuitemcheckbox. F10 фокусирует первое меню, стрелки перемещают фокус, Home/End выбирают начало/конец списка, Enter выполняет команду, Escape закрывает меню и возвращает фокус к его заголовку. Клик снаружи закрывает список без перехвата фокуса. Списки ограничены границами окна и прокручиваются по высоте. Открытый Dialog блокирует меню.

Ctrl+N/O/S/Shift+S и Ctrl+Z/Shift+Z используют те же операции, что и команды меню. Отмена текста в input/textarea/contenteditable остаётся локальной. Форма нового проекта позволяет вернуться к открытому проекту, в том числе сохранённому, до фактического создания другого.

MenuBar находится в ui-kit. Dockview и поиск представлений остаются в workspace-адаптере. Optional registerCanvasActions в PanelProps связывает текущий CanvasPanel с меню через UI-контракт, не изменяя проект или core. Отдельные окна сохраняют прежний заголовок и локальную кнопку языка.

Проверка: tests/app-menu-smoke.mjs входит в общий UI runner. Сценарии существующих функций используют menu-helpers.mjs для перенесённых команд; при проверке прежних кнопок +/↗ они явно включают необязательную панель управления.

Позднее добавлены базовые стадии уведомления и команда «Файл → Экспорт кадра в PNG…»; см. notification-workspaces.md и layer-compositing.md. Новые эффекты, resize существующей сцены, расширенный монтаж и экспорт видео остаются впереди; неработающих пунктов для них нет.
