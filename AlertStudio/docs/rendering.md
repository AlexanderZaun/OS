# Текущее отображение

Обновление 17.10.2026: реализованы общие режимы смешивания, непрозрачность, оттенок/насыщенность, обрезка по ближайшему видимому слою ниже и прозрачный PNG текущего кадра. Описание порядка операций и ограничений — layer-compositing.md. Ниже сохранены сведения предыдущих этапов; утверждения об отсутствии этих функций устарели.

Network поддерживает optional gradient opacity profiles вдоль рёбер по CloudField источника stars. Ограничение: 32 отсчёта на ребро, 24000 на сеть/кадр; превышение requested sampling даёт limit warning. Полностью прозрачные рёбра не рисуются. См. line-mask.md; geometry/sampling остаются в core, Canvas gradient — в adapter эффекта.

Добавлена навигация preview: колесо с привязкой к курсору, pan, кнопки масштаба, 100% и автоматический fit. Bitmap и модель не изменяются; камера независима в каждом экземпляре панели. См. canvas-navigation.md. При CSS scaling checkerboard тоже масштабируется вместе с canvas.

Canvas2D backend принимает text/rect primitives и зарегистрированные специализированные kind через sdk/canvas2d.ts. Координаты — scene pixels, время — секунды, preview масштабируется CSS пропорционально. Прозрачный checkerboard — CSS, он не попадает в пиксели Canvas. Порядок объектов в массиве — back-to-front, Layers показывает его в обратном порядке. Общих blend modes и произвольных масок пока нет.

Текст использует Arial с sans-serif fallback, кириллица проверена в Windows. Явные переносы строк поддержаны; ширина ограничена fillText maxWidth, то есть длинная строка сжимается. Полноценный перенос по словам, overflow policy и воспроизводимая поставка шрифтов остаются задачами переноса textLayout из референса.

Orbit и звёзды — аналитическая анимация, seek пересчитывает их из time. Playback не меняет модель/dirty/history. Общий clock main синхронизирует все Canvas/окна, pause сохраняет кадр и resume продолжает с него. Renderer живёт до закрытия панели, paused-кадр без изменений не перерисовывается. Монтаж и ключи ещё отсутствуют. Дополнительный Canvas требует отдельной работы рендера при изменениях/проигрывании.

core/scene/evaluate кеширует зависимые объекты один раз на кадр, включая скрытые источники. Typed source settings указывают UUID. Network использует те же координаты stars, что и renderer. Порядок вычисления не зависит от z-order. Диагностика missing/wrong/inactive/cycle/limit показана в Canvas; подробности — linked-scene.md.

Собственный процедурный туман реализован отдельно от reference: см. fog.md. Pixel parity с исходником по уточнению пользователя не требуется. Stateful scattering не реализован; для такого режима понадобятся фиксированный шаг/checkpoints. Reference baselines используют replay 60Hz. Экспорт и GPU experiment пока отсутствуют.
