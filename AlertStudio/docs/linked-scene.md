## Как открыть

Создать или открыть проект, затем нажать **«Сцена-пример»** в toolbar. Создаётся новая несохранённая сцена 1920×1080: четыре тумана 900×480, 1900 мелких и 70 крупных звёзд, сеть по крупным звёздам. Если текущий проект изменён, стандартный диалог спрашивает о замене. Сохранение остаётся отдельной командой. Параметры пресета — modules/presets/cloud-network/layers.json, UUID генерируются заново для каждого создания.

Собрать вручную: добавить fog, выбрать «Неровное облако»; добавить stars, выбрать «По облаку» и источник тумана; добавить network и выбрать источник stars. Слой источника можно скрыть через Layers, оставив его доступным вычислению. Нулевая opacity/count источника даёт пустой выход и сообщение у потребителя. «Слой выше/ниже» меняет рисование и поддерживает undo.

## Что добавлено

Fog теперь содержит 27 definitions: cloud shape/roughness, area/rim/mixed, 8–160 клубов, brightness, фаза, эллиптический просвет и качество. Существующие параметры по умолчанию сохраняют самостоятельный режим старого fog. Нормальное качество — поверхность 384×384/texture 96×96, draft 256/64, high 768/192. Маска и шум кешируются; модель публикует базовые/текущие координаты клубов и их аналитические скорости. Совпадающая форма четырёх слоёв в пресете задаётся одинаковыми настройками; отдельного общего объекта формы пока нет.

Stars содержит 41 definition с условным показом. Самостоятельное поле сохраняет старый режим. Cloud field наследует геометрию выбранного fog; доступны world offsets, относительные scale/rotation, centerCount, rim band, uniformity, spread, wander и attachment. Цели привязки выбираются по базовым положениям клубов, а не по меняющемуся ближайшему соседу. Квадраты/круги/ромбы/искры, независимый радиус/цвет glow, opacity ядра, отключаемый белый центр, доля мерцающих элементов и короткие аналитические следы. След привязанного элемента использует локальное блуждание и касательную скорости клубка, без history replay. Sprite extent учитывает лучи/ромбы при малом halo radius.

Network содержит 11 definitions: stars source, distance, neighbors, segments/triangles/chains, center participation, color/width/opacity/glow и point limit. Использует готовые координаты звёзд с тем же поворотом/смещением. Мерцание ядер не меняет состав сети. Spatial cells ограничивают поиск соседей; ID рёбер убирают дубли; затухание по расстоянию смягчает включение/отключение. Default point limit 500, максимум 1000, рёбер не более 3000. При ограничении есть UI notice. Нет ромбов, dash, outline и history-based hysteresis.

## Контракты и сохранение

Setting.type=source, sourceType=effect ID, value=UUID или пустая строка. Значение сохраняется обычным отдельным settings/source.json; Value остаётся примитивным, format проекта 1. Core проверяет назначение на существующий объект нужного типа, self-reference и cycles. Удаление сохраняет ссылку у потребителя для диагностики; duplicate сохраняет связь с тем же источником. Клонирование всей связанной группы с переназначением UUID пока отсутствует.

Effect.evaluate принимает optional третий аргумент EvaluationContext с source<T>(settingId). Старые двухаргументные эффекты совместимы. core/scene/evaluate вычисляет зависимости лениво, кеширует один результат объекта на кадр, затем собирает видимые primitives в пользовательском порядке. Порядок вычисления независим от z-order. Missing/wrong/inactive source, cycle, unavailable/failed effect и network limits показаны в Canvas.

Effect.editor.bounds получает optional context; position может быть функцией от values. Поэтому drag привязанных stars меняет offsetX/Y и показывает рамку наследуемой геометрии. Настройки source и when валидируются Ajv, Properties использует общую тему и RU/EN.

## Общие часы

Playback находится в main, передаётся через именованные IPC snapshot/command/subscription. Все холсты, включая отдельные окна, используют одну временную опору. Команды: toggle, seek, configure(duration/loop/speed). Новый/open/recovered project сбрасывает время и pause. Camera zoom/pan каждого Canvas остаётся независимым.

Clock не входит в проект/undo/recovery: проигрывание не делает проект dirty. Duration/loop/speed — пока runtime preview preferences, между перезапусками не сохраняются; полная шкала/ключи ещё не сделаны. Loop не гарантирует бесшовность всех эффектов: требуется согласовать периоды и скорости конкретной композиции.

## Проверки и ограничения

19 behavior tests и 7 Electron smoke scripts. Новые проверки: old values vs filled defaults, endpoints сети, one evaluation per source/frame, hidden source, cycles/type/missing/limit diagnostics, links roundtrip/reorder/duplicate/delete/undo, pixel replay 6→12→6, linked offsets, общий playback/seek/loop отдельного Canvas, no dirty/history от clock, quality switching и UI 900×650/1920×1080.

Evidence: artifacts/linked-ui-results.json, linked-scene screenshots/frame, tests/linked-render-harness.ts. Harness измеряет 30 синхронных evaluate/draw для всей композиции 1920×1080, отдельно оба времени; без React, vsync, autosave и нескольких окон. Это не гарантия FPS и не длительный memory test.

tests/reference-focused-capture.mjs снимает исходник при t=0/6/12 с replay 60Hz, отключая edge/flow/flying/text/darkBase только в runtime. Результаты — artifacts/focused-reference. Исходный HTML и committed baselines не меняются. Сравнение пока визуальное; автоматической метрики сходства нет.

Остаются: общий редактируемый region для нескольких fog, многократные источники fog у stars, density sampler, дополнительные художественные режимы тумана, длинные следы, дополнительные топологии сети и hysteresis, полный сцепленный preset library, export и GPU. Edge Light/flow/flying из полного примера — отдельные эффекты. Звук и внешние сервисы отложены.
