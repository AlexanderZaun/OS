# Единый стиль AlertStudio

Свойства: поиск и короткие кнопки фильтра/сброса помещаются в узкой панели; полные accessible names сохранены. У поля общая SettingHeading с привязанным label, единицей, текстовой звёздочкой отличия и отдельной кнопкой ↶. Сброс заблокированного слоя отключён. Общие сбросы используют Dialog с описанием областей и числом изменений; фон и контролы наследуют tokens. Поиск может раскрывать группы с найденными параметрами, скрытые поля сопровождаются текстом условия. См. settings-tools.md.

## Компактная компоновка - 17.10.2026

Текущая шапка объединяет бренд, меню и название проекта в строку36px. На ширине до1100 часть бренда/подпись сохранения сокращается, признак dirty остаётся точкой и полным aria-label/title. До650 меню переходит на отдельную строку с горизонтальным доступом ко всем командам. Рабочая область стадий размещает переключатель и короткие подписи настроек в общей строке39px; пояснения открываются кнопкой справки. Диапазоны сборки имеют ширину содержимого, вместо трёх растянутых колонок.

Инструменты широкого Canvas размещаются в строке37px; узкий Canvas переносит группы. Точное поле масштаба остаётся видимым, меню предустановок обозначено стрелкой без повторения процентов. Размер сцены, фаза/прозрачность и справка сведены в одну нижнюю строку25px; полный текст навигации доступен в Dialog. Общий footer23px, вкладки Dockview28px. Короткий холст ограничивает высоту инструментов прокруткой, сохраняется место изображения.

Каталог: initial170/min120px, слои/свойства min160px; ограничения применяются также к восстановленным панелям без сброса раскладки. Вместо высокого заголовка распределения — кнопка «Разделы» с прежними aria-label/title. Имена кнопок и знак + разделены, не переносятся; длинные имена сокращаются с полным title. На узком каталоге скрыты повторяющие категорию пояснения; индивидуальная отметка требования источника при ручном переносе остаётся. Заголовки категорий и узкие строки слоёв сокращаются через ellipsis.

Dialog рисуется через portal в body, чтобы container queries/overflow панели не ограничивали модальное окно. F10 не уводит фокус из диалогов. Снимки compact-main/assembly-1440/1080/compact.png, compact-minimum-catalog.png. Подробности в compact-layout.md. Следующие записи описывают предыдущие этапы.

Четыре области уведомления переключаются общей полосой под меню. Используются токены темы, кнопки с aria-pressed, числовой ввод с Enter/blur и отменой Escape. В «Сборке» видны три диапазона, полный набор настроек раскрывается кнопкой. Ограничения чисел вынесены в title; неверный ввод отмечается рамкой и aria-invalid. Отдельное окно Canvas использует ту же полосу. Layers включают компактные действия при высоте до 420px; минимальная высота Dockview-панели 190px сохраняет рабочую строку списка при 900×650, в том числе в восстановленных раскладках. Снимки notification-main/intro/assembly-compact/1080.png проверяются после стабилизации fit.

Верхнее меню заменяет общую toolbar. MenuBar использует tokens темы, portal для списка вне обрезаемого Dockview и ограничение размеров viewport. Диалоги сведений, справки и переименования используют общий Dialog. По умолчанию панель управления окнами не занимает место; сохранённая раскладка пользователя не меняется. Проверяются app-menu-compact/1080.png и app-menu-window-compact/1080.png; длинный список «Окно» прокручивается внутри окна. Актуальная организация команд описана в application-menu.md; ниже сохранены сведения о предыдущих этапах.

Каталог вынесен из фиксированной колонки в Dockview-панель objects, с теми же вкладкой/закрытием/перемещением, что у слоёв и свойств. Начальная ширина180px/min155, общие tokens и внутренняя прокрутка. Отдельное окно использует этот же компонент. В старую раскладку панель добавляется без сброса пользовательских панелей; восстановление закрытого каталога — через управление панелями. Снимки object-catalog-panel-compact/1080.png проверяются после workspace reset, остальные сценарии перед этим проверяют произвольную пользовательскую перестановку.

Каталог разделён на самостоятельные/связанные кнопки, настройка распределения — общий Dialog. Ручная категория не скрывает реальные требования: несовпадающие элементы имеют пояснение под названием. Каталог прокручивается отдельно при 900×650. Единственная панель «Панели» использует общие controls/tokens и Dockview: один список с +/↗, перетаскиваемая вкладка, внутренняя прокрутка. Начальная высота130px оставляет действия видимыми в компактной раскладке; слои/свойства получают minimumWidth190. Снимки catalog-workspace-compact/1080.png и catalog-sections-dialog.png осмотрены.

Свойства начинают с раздела «Связи с объектами»: доступные source-selects идут первыми, затем управляющие их видимостью режимы. Остальные параметры остаются в прежних группах без дублирования контролов. При выборе другого объекта прокрутка возвращается к началу; используются прежние controls/tokens. Кнопки добавления мелких и крупных звёзд разделены, стиль tool rail сохранён. Снимки object-templates-compact/1080.png просмотрены, источник сети виден без прокрутки в обоих размерах.

Панель управления холстом разделена на навигацию и воспроизведение. При ширине контейнера до 700px подписи «Выбранное»/«Центр» короче, полные accessible labels и title сохраняются; проценты доступны напрямую. Панель использует общие tokens и container queries. Снимки canvas-selected-compact/1080.png проверены.

Панель слоёв использует общие tokens, Dialog и адаптацию по высоте контейнера: отдельная прокрутка списка, закреплённая шапка, нижние действия в одну горизонтально прокручиваемую строку при малой высоте. На 900×650 сохранено место для целой строки слоя; подробности в layers.md.

Источник оформления — ui-kit/theme.css. Shell/layout CSS не вводит отдельную палитру. Новый модуль должен наследовать host font и пользоваться tokens; не добавлять глобальный reset или CSS-селекторы для чужих панелей.

| Роль | Token / правило |
|---|---|
| Фон | --studio-bg, #0d131e |
| Панель/диалог | --studio-surface, #141e2d |
| Контрол/карточка | --studio-raised, #1b293b |
| Поле/холст | --studio-sunken, #0a111c |
| Граница | --studio-border, #2a3c53 |
| Основной/вторичный текст | --studio-text / --studio-muted |
| Акцент | --studio-accent, #91c6ff |
| Ошибка/успех | --studio-danger / --studio-success |
| Контрол | 32px минимум, 6px radius, 12–13px текст |
| Панель | 16px padding, 15px заголовок |

Primary-кнопка обозначает основное действие, обычные кнопки — дополнительные, quiet — вспомогательные. Disabled/focus/hover используют общие правила. Не полагаться только на цвет для ошибок: состояние черновика подписано текстом. Акцентный focus outline не убирается.

Новые in-app окна используют Dialog: одинаковые рамка, заголовок, отступы, прокрутка и фон. Реализованы focus trap, Escape и возврат фокуса. Native Windows file dialogs и prompt закрытия намеренно используют системное оформление; их локализация пока двуязычная.

Dockview имеет собственную внутреннюю обёртку: variables задаются на `.workspace .studio-workspace`, а не только на непосредственном child. Вычисленный background вкладок проверен: rgb(13,19,30). Пример внешней панели использует host class panel-body и наследует тему.

Проверены скриншоты редактора 900×650 и 1920×1080, окна восстановления и Extensions. Малое окно переносит toolbar на вторую строку, панели прокручиваются внутри, document не имеет горизонтального overflow. ОС DPI, увеличение системного шрифта и полная WCAG-аудит проверка ещё не проводились. Артефакты: artifacts/screenshots/editor-compact.png, editor-1080.png, recovery.png, extensions-compact.png.
