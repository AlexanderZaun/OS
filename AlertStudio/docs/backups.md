# Резервные версии на GitHub

Репозиторий: https://github.com/AlexanderZaun/OS

Ветка `main` хранит текущую опубликованную версию. История коммитов сохраняет предыдущие состояния. Дополнительно аннотированные метки `backup/дата-описание` обозначают конкретные резервные версии. Обновление `main` не перемещает эти метки.

## Контрольные версии от 17.10.2026

- `backup/2026-10-17-before-application-menu` — версия 89320d4, до добавления верхнего меню.
- `backup/2026-10-17-application-menu` — версия с верхним меню, сохранением пользовательских раскладок и необязательной панелью управления окнами. Перед публикацией прошли сборка, TypeScript, import boundaries, 54 функциональных теста и 16 сценариев Electron.

## Получить сохранённую версию

1. Открыть репозиторий на GitHub.
2. Открыть переключатель ветки `main` и вкладку `Tags`.
3. Выбрать нужную метку `backup/...`.
4. Нажать `Code` → `Download ZIP`.
5. Распаковать в отдельную папку. Установить зависимости и собрать приложение по README. Windows-сборка создаст Launch.exe.

Архив содержит исходники и документацию, включая PDF сравнения. Установленные зависимости, сгенерированная сборка, временные результаты тестов, настройки компьютера и пользовательские проекты уведомлений вне репозитория в такую резервную версию не входят. Для проектов уведомлений требуется отдельное резервное копирование их папок.

## Дальнейшее сохранение

При публикации следующих завершённых этапов можно создавать новую метку с датой и описанием. Уже опубликованные резервные метки следует сохранять на исходных коммитах. История и метки защищают от потери состояния при обычном обновлении кода; доступ к ним зависит от сохранности репозитория и учётной записи GitHub.

Планировщик и автоматическая отправка изменений этим действием не настраиваются. Новые локальные изменения попадут на GitHub после следующей явной публикации.
