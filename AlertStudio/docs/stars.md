Обновление 17.10.2026: 48 definitions. Добавлено [распределение по плотности тумана](fog-density.md), сгущение и затухание по области источника. Network получает отдельный densityAlpha. Режим включён для мелких звёзд новой сцены-примера. Ниже сохранено описание предыдущих этапов.

Встроенный эффект `stars` версии 0.1.0, кнопка «Звёзды +». 45 отдельных definitions в modules/effects/stars/settings; сохранённые значения остаются отдельными файлами проекта. Добавлен режим Cloud field с fog source, наследуемой геометрией, anchors/wander/attachment, center/rim distribution, square/circle/diamond/spark и отдельными core/halo настройками. Теперь есть независимые блики с яркостью, долей, скоростью и длиной лучей: [настройки оформления](appearance-controls.md). [Подробности связей](linked-scene.md). Описание ниже относится к исходному самостоятельному режиму.

Группы: область (центр, размеры, поворот, равномерное распределение/скопления), звёзды (число 0–5000, размер, разброс, opacity, свечение, доля лучистых звёзд, seed, цвет и палитра), мерцание/движение (глубина/скорость мерцания, дрейф в px/s, направление, разброс глубины).

Модель платформенно независима. Из seed строятся четыре центра скоплений и фиксированное число случайных параметров на звезду. Увеличение count сохраняет начальные звёзды. Мерцание аналитическое с индивидуальными фазами/частотами; дрейф — оборачивание координат по области с затуханием у края. Глубина изменяет скорость дрейфа. Заданный drift — максимальная скорость плана, ближнего к наблюдателю. Нулевые count/opacity возвращают пустой кадр.

Canvas renderer кеширует шесть спрайтов 64×64: три оттенка × точка/четырёхлучевая форма. Текстуры обновляются при изменении цвета, палитры или glow; старые поверхности обнуляются. При удалении/скрытии слоя backend вызывает dispose. Полноразмерных промежуточных поверхностей нет. Поворот и clip совпадают с областью выделения.

Проверены repeat seek по модели и пикселям 6→12→6, pause/resume без сброса, отсутствие redraw неизменившейся pause, независимые копии, нулевое число, schema, RU/EN, folder roundtrip, два размера UI, ограниченный кеш и его освобождение. Evidence: artifacts/stars-ui-results.json, screenshots/stars-1080.png и stars-compact.png. Harness измеряет 20 вызовов **evaluate + render** для 1000/5000 звёзд на Canvas 1920×1080, без React, vsync и записи видео. Это не FPS всей студии и не долговременный тест памяти.

Пока нет падающих звёзд, ручного редактора созвездий, индивидуального поворота, галактической полосы, маски под текст и библиотеки пресетов. Короткие следы, отдельный halo radius, общий clock и сеть по stars уже есть; export host отсутствует. Продолжение — [блок 1](plan/01-fog-and-stars.md).
