# Состояние этапов

Текущий выбранный участок: связанная композиция fog → stars → network. Первый вариант реализован, подробности — linked-scene.md. Добавлены общие preview clocks, reordered layers, source diagnostics, preset и legacy compatibility checks. Монтаж, keys, export, звук и молнии остаются впереди. Ранние статусы ниже описывают предыдущие checkpoints.


Подробный план разделён на **10 блоков** с отдельными файлами: [оглавление](feature-catalog-ru.md). Первые туман/звёзды и выбор/перемещение на холсте реализованы; следующие части — размер/поворот/привязки и молнии. Звук отложен.

- A: исследован пустой репозиторий, найден и сохранён оригинальный HTML, подготовлены аудит и эталоны.
- B: рабочий SDK/loader/validator, отдельные пакеты панели и эффекта; установка в собранный Electron, активация после restart и открытие подтверждены.
- C: холст, zoom/pan/fit, выбор и перемещение text/fog/stars мышью с одним undo, слои, generic свойства, текст, дублирование, visibility, history и отдельные окна подтверждены. Ручек размера/поворота, snapping, panel pin, полноценного переноса экземпляра и monitor recovery нет.
- D: раздельный проект, exact module lock, неизвестные данные, process-failure transaction, sync JSON, проверенный резервный индекс, Windows folder lease, debounce autosave и восстановление черновиков проверены. Power-loss, network-share координация, retention и очистка ревизий не проверены/не реализованы.
- E: собственные fog/stars и специализированный Canvas SDK реализованы; независимые слои, seek replay, прозрачность, save/open и освобождение renderer проверены. Исходник — визуальный ориентир, pixel parity с reference не требуется. Звёзды имеют 20 настроек и bounded sprite cache.
- F: пульсация/дополнительные блоки, preset copy/migrations, external modifier — запланированы.
- G: три этапа, montage, единый clock, звук, seek/history — запланированы.
- H: собственные stars реализованы; flying/flow/lines/edge/strands/scatter и importer запланированы как самостоятельные решения.
- I: PNG/GIF/WebM/MP3, audio modes, bounded export, cancellation, licenses, installer и clean-machine test — запланированы.

Не считать B эквивалентом полной приёмки основы. Текущая версия — рабочий checkpoint runtime-модулей и модели, без обещания завершённой студии.

Интерфейс: единые tokens ui-kit/theme.css, общий Dialog для Extensions/recovery, тема Dockview, компактные поля и состояния кнопок. Проверены реальные окна 900×650 и 1920×1080; дальнейшие панели обязаны использовать ту же систему.

Уточнённый порядок: туман → звёзды → инструменты композиции и следующие эффекты → общая анимация → экспорт без звука. Первые два эффекта готовы в начальном варианте. Звук отложен. [Подробный каталог: 218 возможностей](feature-catalog-ru.md). Молнии — следующий новый эффект после базовых инструментов композиции. Гличи планируются через общий стек модификаторов; преломление — после исследования рендера. Старые этапы G–I описывают направления, а не разрешение заниматься звуком сейчас.
