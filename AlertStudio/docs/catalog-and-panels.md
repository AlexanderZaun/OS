# Разделы объектов и управление панелями

Каталог теперь зарегистрирован как полноценная панель **«Объекты»** (ID `objects`) через UiHost. Фиксированная колонка Shell удалена. В начальной раскладке каталог расположен слева, его вкладку можно перетаскивать и закрывать; через управление панелями доступны «Объекты +» и «Объекты ↗». Отдельный каталог добавляет объекты в общий проект, изменения разделов синхронизируются между окнами. Маркер `alert-studio-object-catalog-v1` однократно добавляет каталог в старую раскладку, сохраняя остальные панели; после намеренного закрытия каталог не возвращается сам при старте. Сброс рабочей области восстанавливает его. Начальная ширина180px, minimumWidth155; содержимое прокручивается внутри панели.

Список добавления содержит два раздела. Исходное распределение относится к текущим настройкам кнопок создания, а не к уже размещённым экземплярам:

| Самостоятельные | Связанные |
|---|---|
| Текст | Мелкие звёзды |
| Туман | Крупные звёзды |
| | Сеть звёзд |

Оба варианта звёзд создаются в режиме cloud, сеть ожидает источник звёзд. Туман создаётся с independent region. Типы, формулы эффектов и связи в существующих проектах не менялись. Звёзды по-прежнему можно переключить в самостоятельный field mode через свойства экземпляра.

«Распределить объекты» открывает общий Dialog с выбором раздела для каждой кнопки. Изменения применяются сразу и сохраняются в localStorage (`alert-studio-object-groups`); есть «Сбросить разделы». Идентичность использует effect/template ID. Записи временно отсутствующих расширений сохраняются; новые элементы получают категорию по активным source definitions и значениям создания. Повреждённые данные игнорируются. Это настройка каталога, без project dirty, Undo/Redo и записи в проект.

Ручное распределение не отменяет требование источника. При несовпадении исходной категории кнопка подписана «Нужен источник» или «Источник не обязателен», а описание раздела — «Ваше распределение». Каталог прокручивается независимо от документа. Интерфейс имеет RU/EN.

Кнопки работы с панелями собраны в единственной Dockview-панели «Панели». Для каждого типа показаны `+` (новый экземпляр внутри редактора) и `↗` (дополнительное отдельное окно). Новый экземпляр первоначально размещается ниже существующего экземпляра этого типа либо другой рабочей панели. Вкладки рабочих панелей и вкладку «Панели» можно перетаскивать между областями Dockview; положение сохраняется. Верхняя кнопка «Панели» активирует имеющееся управление или восстанавливает закрытое, не создавая дубликат. Панель управления исключена из собственного списка. Прежние кнопки вывода окон слева и нижняя полоса добавления панелей удалены.

Старая раскладка при первом обновлении получает панель управления, остальные экземпляры сохраняются. Маркер `alert-studio-panel-manager-v1` позволяет уважать последующее намеренное закрытие управления. Workspace reset возвращает начальные панели, не сбрасывая распределение объектов. Отдельные окна не перезаписывают основную раскладку. Дополнительные холсты видны одновременно и сохраняют независимые камеры. Начальная минимальная ширина слоёв/свойств — 190px; управление прокручивается при уменьшении.

`PanelProps.workspace` — optional UI-контракт с метаданными панелей и действиями open/detach. Dockview API остаётся в адаптере; модуль управления не импортирует Dockview/Electron. Отдельные окна остаются дополнительными представлениями общей модели, а не переносом конкретного экземпляра вместе с его состоянием.

Проверки: tests/catalog.test.ts и tests/catalog-workspace-smoke.mjs. UI-сценарий проверяет категории, ручное распределение/сброс, сохранение после reload без project mutations, native drag вкладки и сохранение положения, дополнительное окно/холст, закрытие/восстановление управления, upgrade старой раскладки, workspace reset, RU/EN и 900×650/1920×1080. Снимки catalog-workspace-compact/1080.png и catalog-sections-dialog.png просмотрены. Условия: сцена1920×1080, transparent, Canvas2D, fog normal quality/seed42, t=0. На снимках пользователь поместил мелкие звёзды в самостоятельные, текст — в связанные; реальные требования подписаны рядом с кнопками.
