# Измерения текущего checkpoint

16.10.2026, Windows, Node 24.19.0, AMD Ryzen 9 5900X 12-Core Processor, RAM 68 598 849 536 байт (63.9 GiB). Исходные результаты: artifacts/performance.json. Команда: `node tools/performance.mjs`. Сцены воспроизводимы: 1, 50 и 200 text объектов с одинаковыми defaults, 1920×1080. Каждый объект — metadata + 5 отдельных значений. Указанное время CPU evaluation не включает Canvas raster и не является временем кадра интерфейса.

| Сцена | Файлов в ревизии и индекс | Save ms | Open ms | RSS процесса |
|---|---:|---:|---:|---:|
| Простая: 1 объект | 12 | 13.95 | 8.94 | 50.6 MiB |
| Типовая для текущего текста: 50 | 306 | 208.96 | 96.34 | 56.4 MiB |
| Тяжёлая для текущего текста: 200 | 1206 | 810.03 | 338.54 | 56.1 MiB |

Один запуск, filesystem cache не сбрасывался, доверительных интервалов нет; RSS — выборка после этапа, **не пик памяти**. CPU evaluate 1000 итераций показала 0.0003/0.0022/0.0017 ms на сцену; такой микробенчмарк чувствителен к JIT и не сравнивает graphics backends.

Туман, particles, GPU frame time, p95/p99 UI edit latency, peak memory и export throughput/cancel ещё не измерены. Целевые показатели для полноценной студии не устанавливались по этим текстовым сценам. Ранний Canvas/Pixi эксперимент обязателен перед выбором сложного render path. Дополнительный Canvas сейчас запускает отдельный loop; стоимость тяжёлых нескольких preview нужно сделать явной и измерить.
