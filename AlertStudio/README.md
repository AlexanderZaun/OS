# AlertStudio — экспериментальная основа

Навигация по холсту: **колесо** — масштаб к курсору, **Пробел + перетаскивание / средняя кнопка** — перемещение, **«Вписать»** — сцена целиком. Масштаб также доступен кнопками −/+ и списком процентов. [Подробности](docs/canvas-navigation.md).

Добавлены собственный туман (**Туман +**, 19 параметров) и звёздное поле (**Звёзды +**, 20 параметров): [туман](docs/fog.md), [звёзды](docs/stars.md). Текст и поля можно выбирать/перемещать мышью; один жест — одно undo, Esc отменяет: [редактирование холста](docs/canvas-editing.md). Ручки размера/поворота и молнии ещё впереди, звук отложен. [План из 10 блоков и 218 пунктов](docs/feature-catalog-ru.md).

Настольное приложение находится целиком в этой папке. Реализованы текстовые объекты, независимые настройки, слои, свойства, Canvas-предпросмотр, undo/redo, дополнительные экземпляры панелей, отдельные окна с общей моделью, многофайловое сохранение и runtime-установка доверенных панелей и эффектов. Это законченный проверяемый участок, не весь продукт из задания.

## Запуск

Windows, Node.js 22.12+ (проверено 24.19), pnpm 11.25. Первичная установка требует сети; работа собранного редактора — офлайн.

```powershell
cd C:\Life\OS\AlertStudio
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

Если pnpm отсутствует в PATH, в этой среде он доступен по пути `C:\Users\Groktor_PC\.cache\codex-runtimes\codex-primary-runtime\dependencies\bin\fallback\pnpm.cmd`.

Уже собранную версию на этой машине можно запустить файлом `Launch.cmd` или командой `powershell -File C:\Life\OS\AlertStudio\Launch.ps1` без pnpm в PATH. Это запуск из рабочей папки, не standalone установщик.

Создайте проект, добавьте «Текст +», измените свойства. «Сохранить» выбирает папку проекта; «Открыть» открывает такую папку. Ctrl+S, Ctrl+Shift+S, Ctrl+Z работают в редакторе. «Свойства ↗» открывает отдельное окно с общей историей; закрытие окна возвращает к основной области. Открытие отдельного окна сейчас создаёт дополнительное представление, а не переносит исходный экземпляр панели.

Правки автоматически сохраняются через 700 мс в отдельный многофайловый черновик вне папки проекта. Его состояние видно внизу окна. После аварии нажмите «Черновики восстановления»: восстановление открывает несохранённую копию. Обычное закрытие дописывает последние правки в черновик. Явное «Сохранить» сохраняет проект и снимает соответствующий черновик с предложения восстановления.

Одна папка проекта не открывается для записи в двух процессах на этой Windows-машине. Если основной индекс повреждён, открывается проверенная предыдущая версия с предупреждением. «Сохранить как» не перезаписывает папку с другим проектом — выберите пустую папку.

## Внешние пакеты

`pnpm build:modules` отдельно собирает `dist/packages/project-info` и `dist/packages/orbit`. В открытом редакторе: «Расширения» → «Установить папку пакета» → выбрать готовую папку → перезапустить приложение. Появятся панель «Информация о проекте +» и эффект «Орбита». Исходники примеров не включены в UI-бандл. Пользователю пакета не нужен npm install. Пакеты хранятся в `app.getPath('userData')/Extensions`, вне установки. `pnpm start -- --safe` отключает пользовательский код.

## Проверки

```powershell
pnpm typecheck
pnpm check:boundaries
pnpm test
pnpm build
pnpm test:ui
pnpm test:recovery
node tests/reference-capture.mjs
```

В управляемом sandbox этой машины pnpm junction-ссылки и операции в перенаправленном TEMP ограничены. Типы, файловые тесты и Electron проверялись разрешённым запуском вне sandbox.

Снимки интерфейса: `artifacts/screenshots`; результаты UI-тестов: `artifacts/ui-results.json`, `artifacts/recovery-ui-results.json`. Кадры оригинального референса: `reference/baselines`. [Общая тема интерфейса](docs/design-system.md), [проверки](docs/verification.md), [требования и статусы](docs/requirements.md), [продолжение](docs/handoff.md).

Туман, модификаторы, монтаж, звук, экспорт PNG/видео, GPU и установщик пока отсутствуют. Полная приёмка основы из задания не пройдена.
